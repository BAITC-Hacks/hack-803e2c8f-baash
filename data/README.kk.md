# Деректер шекарасы

Git ішінде тек схемалар, манифесттер және анық белгіленген синтетикалық сынақ деректері сақталады. Нақты бастапқы жүктемелер, өтініш мәтіні, тікелей идентификаторлар, дауыс, медиа және мекенжайлар осы репозиторийден тыс, қолжетімділігі басқарылатын бекітілген қоймада болуы керек.

- `fixtures/synthetic/` тек контрактілер мен істен шығу күйлерін тексереді.
- `manifests/` генератор нұсқасын, seed, мақсатты және синтетикалық күйді тіркейді.
- `reports/` синтетикалық DQ дәлелдерін, өңірлік DQ тарихи жиынтық санауыштарын және жасырылған карантин жазбаларының толтырғыштарын қамтиды; бұлар модель сапасын дәлелдемейді.
- `schemas/` бекітілген бастапқы сәйкестіктерге арналған; белгісіз өрістер тексеруге дейін карантинде қалады.
