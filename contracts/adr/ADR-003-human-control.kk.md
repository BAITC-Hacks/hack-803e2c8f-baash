# ADR 003 ИИ әрекеттерін адамның бақылауы

Күйі: міндетті

## Шешім

ИИ нәтижесі ұсыныс ретінде беріледі. Платформа өтінішті өзгертпес немесе азаматпен байланыспас бұрын адам түпкілікті тақырыпты, қызметті, басымдықты, дубльдің тиесілігін және жауапты растайды. Детерминдік ережелер тек жеделдікті арттыра алады немесе шұғыл тапсыруды талап етеді; модель ережелер белгілеген басымдықты төмендете алмайды.

## Себептер

- Кейс материалдары азаматтарға әсер ететін шешімдерді адамның бақылауын талап етеді.
- Қазіргі деректер жиындары автономды бағыттауға қажетті, ақпараттың ағып кетуі жоқ толық белгілер тарихын бермейді.
- Түзетулер оқытуға пайдалы белгі береді және олардың авторы сақталуы тиіс.

## Бақылау шаралары

- Кіріс белгілерінің снимогын, модель нұсқасын, бағаларды, іске қосылған ережелерді, адам әрекетін және reason code сақтау.
- Сенімділігі төмен және модель аясынан тыс жағдайларды қолмен басқарылатын каталогқа жіберу.
- Оқиға дубльдерді топтастырғанда әр бастапқы өтінішті сақтау.
- Қабылдауды, тағайындауды, күйді бақылауды және аналитиканы өшірмей, жауап жобасын генерациялауды өшіру.
