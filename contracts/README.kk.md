# Pulse 109 техникалық пакеті

Пакет техникалық тапсырма мен архитектура құжатына қосымша беріледі.

## Құрамы

- `openapi.yaml`: қолданбаның сыртқы және ішкі базалық API-ы.
- `canonical_request.schema.json`: өңірлік адаптерлер үшін өтініштің канондық контрактісі.
- `event_catalog.md`: интеграциялық оқиға конверті, каталогы және үйлесімділік ережелері.
- `model_stack.md`: пилоттың бекітілген мақсатты модельдер стегі, serving топологиясы, резервтік жолдар және іске қосу шарттары.
- `ask-pulse.schema.json` және `analytics-intent.schema.json`: Ask Pulse жауап/экспорт пен жеке inference gateway үшін нұсқаланған JSON Schema; `openapi.yaml` оператор маршруттарын қамтиды.
- `adr/`: алғашқы өндірістік шығарылымды шағын әрі ауыстырылатын етіп сақтайтын шешімдер.
- `diagrams/`: спецификациядағы жобадан алынған архитектура диаграммалары.

## Бекітілген шешімдер

1. Бизнес-модульдер модульдік монолиттен басталады. Модель қорытындысы мен фондық жұмыс бөлек процестерде орындалады, себебі олардың масштабталуы мен ақаулары өзгеше.
2. Өлшенген жүктеме басқа базаның қажеттігін дәлелдегенге дейін PostgreSQL, PostGIS және pgvector транзакциялық әрі іздеу ядросын құрайды.
3. Әр өңірлік жүйе тұрақты канондық контракт пен оқшауланған адаптер арқылы қосылады.
4. Өмірлік цикл тарихы тек толықтырылады. Қазіргі күй — жылдам оқуға арналған туынды снимок.
5. ИИ ұсынады. Адам бағыттауды, басымдық өзгерісін, дубль тиесілігін және генерацияланған жауаптарды растайды.
6. Жоқ және екіұшты күндер сол күйінде қалады. Конвейер уақыт сапасын тіркейді және дәлдікті ойдан шығармайды.
7. Мақсатты пилот ауыстырылатын serving контрактілерінің артындағы XLM-RoBERTa, BGE-M3, BGE reranker v2 m3, Qwen3 8B және Whisper large v3 turbo модельдерінен басталады.

## Тексеру

CI ішінде орындаңыз:

```bash
python -c "import json; json.load(open('canonical_request.schema.json', encoding='utf-8'))"
python -c "import yaml; yaml.safe_load(open('openapi.yaml', encoding='utf-8'))"
```

Іске асыру репозиторийіне OpenAPI linter мен JSON Schema контракт сынақтарын қосыңыз. Адаптер сынақтары дереккөздердің тұлғасыздандырылған fixtures-ін қайта ойнатып, идемпотенттікті, уақыт белдеулерін, карантинді және күйлердің екіжақты сәйкестігін тексеруі тиіс.
