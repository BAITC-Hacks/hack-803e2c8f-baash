# Өңірлік CSV жүктеу адаптері

Берілген жеті өңірлік экспортты `contracts/canonical_request.schema.json` v1.0.0 контрактісіне сәйкестендіреді.

Тек стандартты кітапхана: pandas жоқ, `pyproject.toml` ішінде жаңа тәуелділік жоқ.

## Іске қосу

```bash
python adapters/regional_csv/src/pulse109_regional_csv/ingest.py \
  --src /path/to/exports \
  --out build/ingest
```

2026-09-13 тарихи іске қосуы тіркелген ортада 1 036 858 жол үшін шамамен 24 секунд алды. Бұл қазіргі өткізу қабілетінің кепілі емес. Нәтижелер:

| Нәтиже | Git ішінде | Ескерту |
| --- | --- | --- |
| `canonical.jsonl` | жоқ | 990 000 жазба, шамамен 1.7 GB, сұраныс бойынша қайта жасалады |
| `retrieval_corpus.jsonl` | бар | 14 397 құжаттан тұратын тарихи артефакт; мәтін қазір жасырылған (D-036) |
| `quarantine.jsonl` | бар | 32 тарихи карантин жолы; бастапқы мәндер қазір жасырылған |
| `dq_report.json` | бар | тек жиынтық санауыштар, жол мазмұны мен PII жоқ |

Git-тегі корпус пен карантин файлдары — жасырылған деректердің толтырғыштары; тарихи DQ агрегаттарын тексеруге болады. D-036 бастапқы мәтін мен құпиялық бойынша D-019 орнына жүреді. Бастапқы деректер мен канондық ағын бекітілген, қолжетімділігі басқарылатын қоймада сақталуы тиіс. Clone жасырылған корпустағы тарихи оқытуды қайталауға мүмкіндік бермейді.

## Бекітілген шешімдер

`docs/DECISION_LOG.md` ішіндегі D-013–D-018 қараңыз. Қысқаша:

- Қарағанды күндері M/D/Y ретінде оқылады; 87 709 жол америкалық ретті растайды.
- Түркістан `incidentid` бойынша соңғы `updateddate` дейін ықшамдалады.
- Павлодар бөліктері біріктіріледі; ортақ идентификаторлары жоқ.
- Ақмоланың бағаны ығысқан жолдары эвристикалық түзетусіз карантинге жіберіледі.
- `location.normalization_status` дерлік барлық жазбада `missing`. Координаттар Қостанайдың 20 591 жолының 23-інде және Түркістанның 98 876 жолының 264-інде бар.

## Деректерде не жоқ

Сегіз файлдың ешбірінде азамат мәтіні жоқ. Жалғыз еркін мәтінді орындаушы жабудан кейін жазған. Таза қазақша жазбалар жоқ: 96.9% орысша, 3.0% аралас, 0.1% белгісіз, `kk` жоқ.

Бұл дерек иесінен бастапқы өтініш мәтіні мен бекітілген қазақша тест жиынын сұраудың негізі.

## PII өңдеу

Жасыру жазудан кейін емес, алдында орындалады. Нақты экспорттар тексеруі орындаушы мәтінінен 10 ЖСН мен 93 телефонды, ШҚО бағандарынан 22 347 көше және 6 499 есім мәнін тапты.

Тікелей идентификаторлар канондық жазбаға жетпейді. Мекенжайлар `PULSE109_TOKEN_SALT` тұзымен мөлдір емес токендерге айналады; жергілікті әзірлеуден тыс бұл мән құпиялар қоймасынан алынуы тиіс.
