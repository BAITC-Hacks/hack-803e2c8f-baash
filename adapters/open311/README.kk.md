# Open311 үйлесімділік сынақ ортасы

Бұл процесс контрактілерді желісіз тексеруге қажетті Open311 v2 `services.json` және `requests.json` құрылымдарының шектеулі нұсқасын іске асырады. Ол анық синтетикалық, деректерді тек процесс жадында сақтайды және алғашқы өңірлік адаптер емес. Нақты енгізу үшін жүйе иесі, протокол, кіру деректері, ресми қызмет кодтары, күй сәйкестіктері және растау семантикасы келісілген болуы керек.
