# Модель мен саясатты кері қайтару

## Model alias

1. Жаңа нұсқаларды ілгерілетуді тоқтатып, кері қайтаруға себеп болған бағалауды/оқиғаны тіркеңіз.
2. Өзгермейтін тізілім манифестінен ағымдағы champion және rollback alias мәндерін анықтаңыз.
3. Кері қайтару артефактінің хешін, model card, кіріс келісімшартын, алдын ала өңдеу нұсқасын және лицензиясын тексеріңіз.
4. Serving alias мәнін бекітілген rollback нұсқасына атомарлы түрде ауыстырыңыз; артефактілерді алмастырмаңыз.
5. Трафикті қалпына келтірмес бұрын келісімшарт, қауіпсіздік кластары, калибрлеу және резервтік CPU жолының smoke tests тексерулерін орындаңыз.
6. Alias-тің екі өзгерісін де және бекітуші қатысушыны/тексерушіні аудит дәлелдері ретінде сақтаңыз.

Репозиторийдегі синтетикалық MLflow-compatible манифест бұл процесті нақты модельді ілгерілетпей тексереді.

## Бағыттау, SLA немесе сенімділік саясаты

1. Нашар нұсқаның белсендірілуін тоқтатыңыз; оны орнында ешқашан өңдемеңіз.
2. `rollback_version` мәніне сілтейтін тек қосылатын `rollback` ревьюін жасаңыз.
3. Қосарлы бақылаудан кейін нашар нұсқаның қолданылу аралығын жауып, бұрын бекітілген нұсқаны нақты көрсетілген UTC уақытында белсендіріңіз.
4. Тек туынды проекцияларды қайта есептеңіз. Өтініштердің тарихи шешімдерін немесе SLA уақытын қайта жазбаңыз.

Сәйкестендіру, тексеруші және бекіту сілтемелері бапталғанша production alias немесе саясат өзгертілмейді.
