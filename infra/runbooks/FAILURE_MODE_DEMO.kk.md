# Істен шығу сценарийлерін көрсету

Тек синтетикалық деп белгіленген тест деректерін пайдаланыңыз.

1. `make up` арқылы жергілікті топологияны іске қосып, барлық readiness endpoints тексеріңіз.
2. Өтініш жасап, оның Pulse ID және correlation ID мәндерін тіркеңіз.
3. Қолжетімсіз production model alias сұраңыз. API қауіпсіз `503` жауабын беретінін тексеріп, содан кейін қолмен бағыттау шешімін және тағайындауды жазыңыз. Өтініш, аудит жазбасы және outbox оқиғасы бар болуы керек.
4. Replay adapter-ді қолжетімсіз режимде іске қосыңыз. Жеткізу `retrying` күйіне өтетінін, өтініш синхрондауды күтіп тұрғанын және қабылдау, мәртебелер мен аудит қолжетімді екенін тексеріңіз.
5. Replay adapter-ді қалпына келтіріңіз. Тұрақты worker `available_at` уақытынан кейін оқиғаны алып, сыртқы түбіртекті алуға, жеткізу әрекетін жазуға және outbox жолын `published` деп белгілеуге тиіс.
6. Белгісіз бастапқы мәртебені жіберіңіз. Ол өтінішті өзгертпей `mapping_review` күйіне өтетінін тексеріңіз.
7. Inference-ті толық тоқтатып, қабылдауды, қолмен шешім қабылдауды, тағайындауды және мәртебені жаңартуды қайталаңыз.
8. Жеке деректері жасырылған журналдарды, SQL сандарын, correlation ID және хештерді сақтаңыз. Сұрау денелерін немесе PII ешқашан жазбаңыз.

Автоматтандырылған баламалар `tests/resilience` және `tests/e2e/test_golden_flow.py` ішінде орналасқан.
