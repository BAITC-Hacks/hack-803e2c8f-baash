# Пайдалану нұсқаулықтары

- [BACKUP_RESTORE.md](BACKUP_RESTORE.kk.md) — үстінен жазбай қалпына келтіруді тексеру және тұтастықты салыстыру.
- [CALL_RECORDING_GATE.md](CALL_RECORDING_GATE.kk.md) — аудионың құқықтық, құпиялық, ARI, storage және резервтік талаптары.
- [FAILURE_MODE_DEMO.md](FAILURE_MODE_DEMO.kk.md) — қолмен/outbox резервтік жолы бар ML және адаптер істен шығуын қайталау.
- [MODEL_POLICY_ROLLBACK.md](MODEL_POLICY_ROLLBACK.kk.md) — өзгермейтін model alias және қолданыстағы саясатты кері қайтару.
- [PILOT_DEPLOYMENT_REQUIREMENTS.md](PILOT_DEPLOYMENT_REQUIREMENTS.kk.md) — берілетін инфрақұрылым талаптары, OIDC баптауы және расталған релиз/қалпына келтіру дәлелдері.
- [SECURITY_PRIVACY.md](SECURITY_PRIVACY.kk.md) — сәйкестендіру, объектілерге қолжетімділік, PII, тәуелділіктер, SBOM және сканерлеу тексерулері.
- [RELEASE_REHEARSAL.md](RELEASE_REHEARSAL.kk.md) — қорытынды дәлелдер және кері қайтару реті.

Production RPO/RTO, сақтау мерзімі, сәйкестендіру, сыртқы жүйелер және инфрақұрылым мақсаттары сырттан бекітуді талап етеді; бұл рәсімдерден оларды ешқашан шығарып анықтамайды.
