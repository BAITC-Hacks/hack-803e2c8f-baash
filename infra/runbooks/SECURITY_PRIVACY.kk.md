# Релиздің қауіпсіздігі мен құпиялығын тексеру

- Жергілікті емес API профильдері issuer, audience, жарамдылық мерзімі, рөлдері және өңірлері тексерілген bearer token талап етеді. Development identity тақырыптары pilot және production режимдерінде өшірілген.
- Басқа өңірдің деректерін оқу, өзгерту, есептер және тапсырмаларға қолжетімділік объектінің бар екенін ашпай `403`/`404` қайтаратынын тексеріңіз. Экспорт үшін тексерілген мақсат қажет; жолдар шегі мен жасыру метадеректері сақталады.
- Бастапқы есімдер, мекенжайлар, идентификаторлар, телефондар, өтініш мәтіні, токендер және сұрау денелері журналдарда, метрикаларда, трассаларда, ерекшелік денелерінде және есеп метадеректерінде жоқ екеніне көз жеткізіңіз.
- TLS/mTLS termination, БД/объектілік қойманы шифрлау, secret store арқылы құпияларды енгізу, кілттерді ауыстыру, backup шифрлау, сақтау мерзімі және жоюды тағайындалған инфрақұрылым/құқық жауаптыларымен растаңыз.
- CI ішінде бекітілген тәуелділіктер аудитін, репозиторий құпияларын сканерлеуді, SBOM жасауды және контейнер осалдықтарын тексеруді орындаңыз. Шешілмеген high/critical нәтижелер релизді бұғаттайды.
- Зиянды өтініш мәтінін дерек ретінде тексеріңіз: ол құралдарды шақыра алмайды, өкілеттікті кеңейте алмайды, SQL таңдай алмайды, саясатты өзгерте алмайды немесе жасалған жауапты жібере алмайды.
- Open311, replay, geocoder/tile, қоңырау жазу және синтетикалық деректерді анық белгілеңіз; бұлардың ешқайсысы жұмыс істейтін мемлекеттік интеграцияны немесе құқықтық мақұлдауды білдірмейді.
