# Релизді қайталау және кері қайтаруды тексеру

1. Келісімшартты, migration head, dependency locks, синтетикалық демо манифестін және model aliases мәндерін бекітіңіз.
2. `make lint`, `make typecheck`, `make test`, `make contract-test`, `make e2e`, `make build`, `make load-test`, барлық ML бағалау тапсырмаларын және Compose health/integration tests тексерулерін орындаңыз.
3. Істен шығу, қалпына келтіру, модель/саясатты кері қайтару және интерфейс қолжетімділігі бақылау тізімдерін орындаңыз.
4. Релиз дәлелдерінің индексін жасаңыз. Релизге жауапты адам әр хешті тексеріп, бекітілген қол қою жүйесімен қол қояды; репозиторий өзіне өзі мақұлдау бере алмайды.
5. Image digests және сканерлеу нәтижелерін тіркеңіз. Өзгермейтін digest бойынша орналастырып, қателер/outbox/адаптер және деректердің өзектілігі сигналдарын бақылаңыз; содан кейін бекітілген өзгеріс аралығында релизді ілгерілетіңіз немесе кері қайтарыңыз.

Аяқтау критерийлері B01–B10 бөгейтін тұжырымдарды қамтымайды: нақты өңірлік интеграция, модельдің репрезентативті сапасы, ұлттық қамту, міндетті SLA, production OIDC, заңды сақтау мерзімі, GPU қуаты және RTO/RPO.
