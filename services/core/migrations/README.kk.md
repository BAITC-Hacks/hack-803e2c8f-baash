# Негізгі дерекқор миграциялары

`DATABASE_URL` орнатып, Alembic-ті `services/core` ішінен іске қосыңыз. URL SQLAlchemy-дің синхронды немесе асинхронды PostgreSQL драйверін пайдалана алады. Миграциялар тек алға орындалады; қолданылғаннан кейін оларды өзгертуге болмайды.
