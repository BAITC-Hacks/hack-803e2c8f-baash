# Ask Pulse

Ask Pulse — Operations Center ішіндегі табиғи тіл аналитикасы. RU не KK сұрағы қатаң нұсқаланған intent пен рұқсат етілген метрика сұрауына айналады. Core сандарды есептейді, web алынған график спецификациясын көрсетеді. Парсер мен қосымша LLM SQL жасамайды, көрсетілетін жауапты есептемейді, өтінішті өзгертпейді және бағытын шешпейді.

## Орындалу ортасы және деректер шекарасы

Демо нақты API, PostgreSQL аналитикалық оқу моделін, миграциялар мен тек қосылатын сұрау аудитін қолданады. Муниципалдық жазбалар, тұлғалар және каталог анық синтетикалық. Жадтағы fixture жергілікті және сынақ контракт тексерулеріне қолжетімді; ол PostgreSQL демосын не өндірістік ортаны алмастырмайды. Дерекқор не аудит қоймасы қолжетімсіз болса, айқын ақау күйі беріледі.

Өңірлерді қамту тіркелген көздер мен олардың жаңалық бағасынан анықталады. Жоқ және ескірген көздер әр нәтижеде көрінеді. Бұл жиырма өңірдің толық жиыны емес: ресми манифест пен қалған көздер B01 болып қалады. Тақырып пен қызмет баламалары белсенді каталогтан алынады; синтетикалық жазбалар жұмыс профиліне кірмейді. Бекітілген таксономия мен SLA саясаты B06 болып қалады.

Ask Pulse `appeals_volume/2.0.0` қолданады; бар `/analytics/query` әдепкіде `appeals_volume/1.0.0` және бақылау уақытының мағынасын сақтайды. 2.0 нұсқасы сенімді бизнес-уақытты, адам растаған тақырып/қызмет өлшемдерін және уақыт сапасы алып тастауларын ескі тұтынушыларды жасырын өзгертпей қосады.

Агрегацияға сенімді бизнес-уақыт қажет. Жоқ және екіұшты уақыт саны мен шектеулері шығу тегінде көрсетіліп, алынып тасталады. Бақылау не импорт уақыты бизнес-оқиға уақыты ретінде жасырын көрсетілмейді.

Сұрақтың күнтізбелік кезеңдері Қазақстанның +05:00 шекарасын, график ұяшықтары метрика анықтамасындағы UTC-ті қолданады. Cutoff — сұралған бизнес-кезеңге тәуелсіз оқу снимогындағы көздің ең соңғы бақыланған жазбасы. Сондықтан кеш импорт тарихи бизнес-уақыт сұрауына кіре алады. Күні жоқ алынып тасталған жазбалар таңдалған аумақта саналады; оларды сұралған кезеңге жатқызуға болмайды.

Тексерілген, әрекет ету күні бар баламалар `analytics.intent_alias` ішінде сақталады және тіркелген өңірге немесе белсенді тақырып/қызметке сілтейді. Өндірістік баламалар approval reference талап етеді, демо баламалары синтетикалық. Балама қосу өңірлік қамтуды жасамайды. Болжам үздіксіз өлшенген күндік тарихты талап етеді және үзілістерді жоқ деректен ажырата алмаса, бас тартады. Бақыланбаған өңірлер мен уақыт ұяшықтары жоқ күйінде қалады. Бекітілген жаңалық саясаты бүкіл кезеңнің толықтығын растамайынша, жолдың жоқтығы нөл ретінде көрсетілмейді.

## Қолданылатын сұрақтар мен шектеулер

- Көлем мен уақыт трендтері, өңірлерді салыстыру және тақырып құрылымы.
- Ұзақтығы бірдей алдыңғы кезеңмен салыстыру. Жоқ, ескірген не жартылай салыстыру сенімді өсу пайызын бермейді; нөл базасында пайыз анықталмайды.
- Сақталған белсенді Radar ескертулері. Өсу өздігінен аномалия емес; бос тізім аномалия жоқтығын дәлелдемейді.
- Репозиторийде бар Data Lab аналитикасы арқылы тапсырулар.
- Жеткілікті сенімді тарих болса, бір, екі не үш айға seasonal-naive көлем болжамы. Тарих тапшылығы ашық көрсетіледі; калибрленген интервал, оқытылған сапа саны немесе қызметкер саны ойдан шығарылмайды.

Екіұшты өңір не кезең `clarification_required` және таңдау нұсқаларын береді. Қолданылмайтын, қауіпті, себептік немесе бекітілмеген саясат сұрақтары бақыланатын себеппен `abstained` береді. Қойма не мүмкіндік қолжетімсіз болса, `unavailable` беріледі. Бұлар нөлі бар сәтті нәтиже емес.

## UI және қайталанушылық

Панельде жергілікті тілдегі сұрақтар, ұсыныстар мен жалғастырулар, контекст белгілері, сандар және детерминдік SVG сызық/баған графиктері бар. Қалыпқа келтірілген контекст пайдаланушы мен өңірге байланған қолтаңбалы токенде сақталады. Жаңа сұрақ контексті тазалайды; өңір өзгерсе, панель қайта құрылады. Браузер әңгіме мәтінін local storage-ге сақтамайды.

Нәтиже синтетикалық белгіні, қамтуды және cutoff көрсетеді. **Как рассчитано** / **Қалай есептелді** метрика нұсқасы мен анықтамасын, кезеңді, көздерді, алынған жазбалар мен шектеулерді ашады. Графиктің кестелік баламасы бар. Болжам шекаралары тек айқын қайтарылса көрсетіледі.

**Показать обращения** сол тексерілген intent үшін аутентификацияланған ашу endpoint-ін шақырады. Ол белгісіз бизнес-уақытты сақтап, азамат мәтіні мен жеке сілтемелерсіз метадеректер көрсетеді. PDF және Excel қолтаңбалы нәтиже снимогын сервер renderer-іне жібереді: база өзгерсе де файл көрсетілген жолдар мен cutoff-ты қолданады. Жүктеу мен ашу тұлға/өңір тексерулерін қайталайды; экспорт рұқсат етілген мақсатты талап етеді. `NEXT_PUBLIC_PULSE109_EXPORT_PURPOSE` мәнін енгізудің бекітілген мақсатына сай орнатыңыз. Әзірлеудегі `analytics-review` құқықтық негізді бекітпейді және сервердің тексерілген тұлға мақсатын бақылауын айналып өтпейді.

## Интерфейстер

| Endpoint | Мақсаты |
| --- | --- |
| `POST /v1/analytics/ask` | сұрақ, locale және қосымша қолтаңбалы контекст; `ask-pulse-v1` қайтарады |
| `POST /v1/analytics/ask/drilldown` | қолтаңбалы контекст пен шектелген limit; өтініш метадеректері |
| `POST /v1/analytics/ask/export` | қолтаңбалы нәтиже токені мен PDF/XLSX форматы; бинарлық тіркеме |
| `POST /v1/inference/analytics-intent` | қосымша жеке inference gateway; тек қатаң intent |

Жергілікті LLM орнатылмаса немесе gateway істен шықса, қолданба детерминдік CPU парсерін қолданады. Жергілікті модель міндетті емес және нұсқаланған шекара мен модель баламалары арқылы ауыстырылады. Интерфейс Qwen/Gemma салмақтары не сапасын білдірмейді. Модельді бекіту, RU/KK бағалау және GPU — бөлек енгізу жұмысы; B09 ашық. Қалыпты оператор панелі үміткерлерді таңдамайды. Gateway парсер метадеректерін берсе, нәтиже модель баламасын, runtime және резервтік жол себебін көрсетеді. Бағалау үміткерлері айқын валидацияланбаған.

Жеке intent gateway арқылы тек сұрақ, шектелген каталог және қалыпқа келтірілген контекст өте алады. Азамат жазбалары, PII және агрегаттар Core ішінде қалады. Сұрақтар уақытша және өздері сезімтал дерек қамтуы мүмкін; олар логтарға, metric labels немесе сұрау аудитіне жазылмайды. Аудит сұрақ хешін, парсер нұсқасын, тексерілген құрылымдық intent/query, аумақты, нәтиже күйін және cutoff сақтайды.

## Демо бағыты

 [Демонстрация runbook-ын](../GOLDEN_DEMO.kk.md#қазыларға-арналған-қысқа-жол) қараңыз. Inference тоқтаса да қолмен өтініш жолы қолжетімді. Мүмкіндік B01–B10 жаппайды және өндірістік сәйкестендіруді, құқықтық негізді, сақтау мерзімін не нақты өңірлік интеграцияны бекітпейді.

## Тарихи тексеру

Келесі сандар 120 күндік Golden World-қа дейінгі алғашқы Ask Pulse тексеруіне қатысты, қазіргі seed не HEAD сандары емес; [қазіргі тексерулерді](../DEVELOPMENT.kk.md) және [енгізуді](../../infra/runbooks/PUBLIC_DEPLOYMENT.kk.md) қараңыз.

`0024_ask_analytics_read_model` дейінгі миграция тізбегі екі тәуелсіз PostgreSQL тексеруінде бос базадан қолданылды; барлық 23 сынақ екі уақытша базада өтті. Docker демосын тексеру images-ті қайта жинап, миграцияларды қолданып, нақты PostgreSQL ортасын seed-пен толтырды, API маршрутын өтіп, 134 синтетикалық өтініші бар таза әлемді қалпына келтірді. Қайталанған seed өзгермейтін Replay Lab снимогын қоса алғанда идемпотентті екені расталды.
