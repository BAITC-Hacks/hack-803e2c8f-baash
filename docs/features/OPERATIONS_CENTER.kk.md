# Operations Center

## Қай сұраққа жауап береді

Жиынтық панель жауап беретін «жұмыс қанша» деген сұрақпен шектелмейді; басшы шешуі тиіс «қалаға дәл қазір қай жерде назар керек» деген сұраққа жауап береді.

## Құрамы

`GET /v1/operations/attention-feed` екі бөлікті қайтарады.

**Қала пульсі**: жазба санауыштары — ашық өтініштер, белсенді оқиғалар, жаңа заңдылықтар, жауаптысыз оқиғалар, кезектегі және қате жеткізулер. Бұлар бағалар емес, нақты сандар.

**Назар лентасы**: әр тармағы ашылатын нысанды көрсететін реттелген тізім. Әрекетке жолы жоқ белгі шуға айналып, экранды елемеуге үйретеді.

| Түр | Негіз |
| --- | --- |
| `emerging_cluster` | Radar-дың ашық немесе тексеріліп жатқан кластері |
| `unowned_incident` | шектен ұзақ белсенді және қызметі жоқ |
| `adapter_lag` | жеткізілмеген ең ескі outbox жазбасы |
| `closure_review` | дәлелсіз жабылған өтініштер |

## Қайталанатын маңыздылық

Модельмен емес, сан мен жас бойынша анықталады. Басшы ретті қолмен қайта шығара алады — осы қасиет басымдық экранын тексерілетін етеді.

## Санауыш пен лента әртүрлі нәрсе айтады

Санауыш күйді, лента шектен асуды көрсетеді. Жауаптысыз бір оқиға санауышта болып, лента бос қалуы мүмкін. Бос күй мәтіні ештеңе болмай жатқанын айтпай, осыны түсіндіреді.

## Мұнда жаңа анықтау алгоритмі жоқ

Кластерлер Radar-дан, тоқтап қалған жеткізулер outbox-тен, жауаптысыз оқиғалар оқиғалар кестесінен келеді. Модульдің құндылығы — реттеу және әрекетке бағыттау.
