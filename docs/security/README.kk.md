# Қауіпсіздік туралы ескертпелер

M0/M1 шекарасында канондық және операциялық құрылымдар тек мазмұны ашылмайтын жеке сілтемелерді сақтайды. Сәйкестендіру, сақтау мерзімі, production кілттерін басқару және орналастыруды бақылау сыртқы кедергілер болып қала береді.
