# Pulse 109: запуск и маршрут демонстрации

Основной маршрут показа — [Golden Demo](GOLDEN_DEMO.md). Он связывает одно новое
обращение с операторским решением, Radar, Incident War Room и Ask Pulse.
Данные вымышленные; FastAPI, PostgreSQL, миграции, audit, outbox, worker и
Next.js работают обычным кодом приложения. Внешняя доставка идёт в replay
adapter, а не в региональную CRM.

## Публичный показ

[Landing](https://baash.govtech-kz.com/) → [demo](https://baash.govtech-kz.com/demo). Это PostgreSQL-backed профиль, а не browser mock. Host operations описаны в [PUBLIC_DEPLOYMENT](../infra/runbooks/PUBLIC_DEPLOYMENT.md). Локальный `prepare/verify/reset` ниже управляет `pulse109-demo`, не VPS `pulse109-final`. Перед новым Radar scan сверьте свежесть водного сценария: старый seed сохраняет timestamps.

## Локальная подготовка

Нужны Docker Desktop с работающим Linux engine, Python 3.10–3.13, `uv` и
свободные порты 3000, 5432 и 8080–8084. Из корня репозитория:

```powershell
uv sync --all-groups --frozen
.\demo.ps1 prepare
```

Для macOS/Linux: `uv run python scripts/demo_runtime.py prepare`. Команда
поднимает отдельный Compose-проект `pulse109-demo`, выполняет API walkthrough,
удаляет только тома этого demo-проекта, создаёт чистый мир и проверяет его через
API. Дождитесь строки `PULSE 109 DEMO READY`. Если её нет, демо не подготовлено.

После подготовки откройте [интерфейс](http://localhost:3000/demo). Режим
ведущего доступен по адресу
[?presenter=1](http://localhost:3000/demo?presenter=1). Кнопка пресета только
заполняет вымышленное обращение; отправка и дальнейшие решения остаются за
человеком. Перед повторным показом снова выполните `prepare`.

[Golden Demo](GOLDEN_DEMO.md). Не заучивайте значения счётчиков: они зависят от
состояния базы. Radar показывает совпадение во времени, географии и теме; он
не устанавливает причину происшествия.

## Если жюри попросит подробнее

- **Операционная надёжность:** в очереди покажите ручное назначение,
  `Queued → Delivered` через outbox и worker, затем timeline и audit. Ответ
  replay adapter синтетический.
- **Закрытие и доказательства:** на подготовленном обращении покажите
  предзагруженный SHA-256 evidence reference, preflight и подтверждение
  оператором. Не называйте demo scanner production-антивирусом.
- **Data Lab:** откройте показатель качества времени и список записей с
  отсутствующим business time. Такие записи не получают выдуманный timestamp.
- **Ask Pulse на казахском:** задайте
  `Соңғы 7 күнде өтініштер саны қалай өзгерді?`; покажите график, покрытие и
  происхождение результата.
- **Replay Lab:** синтетические записи исключены из оценки качества модели.
  Нулевая оценочная выборка должна оставаться видимой, а не превращаться в
  «успешный» показатель.
- **ML fallback:** рабочий runtime использует lexical CPU routing и fallback
  retrieval. Fine-tuned classifier и citizen-text embeddings не подтверждены
  для показа; при остановке inference ручной путь остаётся доступным.

## Операционные команды

| Команда              | Назначение                                                         |
| -------------------- | ------------------------------------------------------------------ |
| `.\demo.ps1 prepare` | Полный проход, чистый seed и проверка Golden Demo.                 |
| `.\demo.ps1 verify`  | Базовый API walkthrough, затем чистый seed.                        |
| `.\demo.ps1 status`  | Состояние контейнеров.                                             |
| `.\demo.ps1 down`    | Остановка с сохранением demo-томов.                                |
| `.\demo.ps1 reset`   | Удаление только томов `pulse109-demo`; после него нужен `prepare`. |

`PULSE109_DEMO_NOW` можно использовать для воспроизводимых тестов, но живой
Radar берёт системное время. `prepare` отклоняет закреплённые часы, если они
расходятся с текущим временем более чем на пять минут. Повторный `seed`
сохраняет уже созданные решения; для одинакового начального мира используйте
`prepare`.

## Границы показа

- Сценарий детализирован для Алматы. Синтетический город не подтверждает
  покрытие 20 регионов или национальную статистику.
- Demo-каталог содержит четыре синтетические темы маршрутизации, а фоновые
  записи — пять семейств тем. Требование о десяти темах остаётся открытым.
- Нет production identity provider, утверждённых taxonomy/SLA, правовых
  оснований и регионального API. См. [текущий статус](FEATURE_STATUS.md) и
  [внешние блокеры](../DECISIONS_AND_BLOCKERS.md).
- Если PostgreSQL недоступен, readiness и seed останавливаются. In-memory
  repository не подменяет demo PostgreSQL.
