# Карточка ведущего Pulse 109

Точная команда подготовки и полный маршрут: [Golden Demo](GOLDEN_DEMO.md).
Публичный вход: [demo](https://baash.govtech-kz.com/demo); для нового водного сканирования требуется свежий мир, см. [VPS runbook](../infra/runbooks/PUBLIC_DEPLOYMENT.md). Для локального показа выполните `.\demo.ps1 prepare` и дождитесь строки
`PULSE 109 DEMO READY`. Откройте `http://localhost:3000/demo?presenter=1`.

| Шаг          | Действие                                                                   | Что сказать                                                                                                                                       |
| ------------ | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Обращение | Заполнить пример с водой, проверить текст, отправить вручную               | «Гражданин отправляет новое обращение через обычный API. Данные вымышленные.»                                                                     |
| 2. Оператор  | Открыть созданный ID в очереди, запросить рекомендацию, подтвердить        | «Лексический базовый алгоритм предлагает маршрут; человек принимает решение. Показанные оценки ранжируют варианты и не измеряют точность модели.» |
| 3. Radar     | Вернуться в Операционный центр, выполнить скан за 6 часов, открыть кластер | «Новые сообщения близки по времени и месту. Система не утверждает причину.»                                                                       |
| 4. War Room  | Создать инцидент из кластера, показать footprint и advisory                | «Каждое обращение сохранило свой ID и историю. Инцидент связывает работу служб.»                                                                  |
| 5. Ask Pulse | Показать вопрос за 7 дней, расчёт, исходные обращения, PDF/Excel и прогноз | «Ответ собран из записей PostgreSQL, и его можно раскрыть до источника. Прогноз построен на синтетической истории.»                               |

Не называйте demo национальным покрытием: сценарий детализирован для ALA.
Исторические экспорты покрывают 7 из 20 регионов. Текущий demo содержит 5
семейств тем и 4 синтетические темы маршрутизации. Настоящая региональная CRM,
официальная таксономия и проверенная ML-точность остаются внешними блокерами.

Если спросят про отказ ML, покажите ручное решение в очереди: создание
обращения, маршрутизация, статус и аудит работают без inference. Если спросят
про проверку модели, откройте Replay Lab и поясните, что синтетические случаи
исключены из оценки качества.
