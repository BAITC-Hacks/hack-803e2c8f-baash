# Модель паспортының үлгісі

Нақты артефакт үшін толтырыңыз. Тексеруге дейін мысал толтырғыштарын алып тастаңыз; паспорт файлы бекітуді білдірмейді.

| Өріс | Міндетті мән |
| --- | --- |
| Бірегейлік | Model ID, тапсырма/сұрақ түрлері, артефакт SHA-256, базалық модель және бекітілген лицензия/revision |
| Күй | `NOT_VALIDATED`, `EVALUATION_ONLY`, `ADVISORY_TRIAL` немесе бөлек бекітілген жұмыс күйі; бекітуші/күн |
| Кірістер | Шешімге дейінгі рұқсат етілген белгілер, тұлғасыздандыру/алдын ала өңдеу нұсқасы, таксономия/сұрақ/нұсқа нөмірі, тыйым салынған өрістер |
| Деректер | Train/calibration/test ID-лері мен хештері, рұқсат/құқықтық сілтеме, cutoff, өңір/тіл сандары, синтетикалық үлес |
| Әдіс | Архитектура, оқыту seed-і/код пен lock хеші, loss, калибрлеу кесіндісі, OOD/бас тарту тәсілі |
| Нәтижелер | Baselines, тест саны, кесінділердегі тиісті routing/retrieval/pairs метрикалары, калибрлеу, таңдамалы тәуекел, сенімділік интервалдары |
| Өнімділік | Жабдық, batch size, p50/p95 кідірісі, жад, CPU/GPU резервтік жолының мінез-құлқы |
| Қауіпсіздік | PII және ағып кету тексеруі, белгілі ақаулар, адамның растау шекарасы, ауытқу/drift мониторингі |
| Пайдалану | Орналастыру профилі, Decision Gateway саясатына байлау, кері қайтару артефактісі, иесі және келесі тексеру күні |

Бекітілген деректер не белгілер болмаса, synthetic fixtures-тен сапа бағасын ойдан шығармай, жоқтық себебін және null/қолжетімсіз мәнін көрсетіңіз.
