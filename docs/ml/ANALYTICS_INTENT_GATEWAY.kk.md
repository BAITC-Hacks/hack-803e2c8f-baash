# Ask Pulse жергілікті инференсі

`POST /v1/inference/analytics-intent` эндпоинті сұрақты табиғи тілден
`AnalyticsIntent`-ке аударады; ол ешқашан статистиканы есептемейді және азаматтардың жазбаларын оқымайды.
Қолданыстағы `/v1/inference/classify` келісімшарты қолжетімді болып қала береді.

Шлюз шектелген сұрақты, локальді, айқын эталондық сағатты және
қолжетімділік аймағы берілген `IntentCatalog`-ты қабылдайды. Шектеуші JSON схемасы модель шығысын қолданыстағы
метрикалармен және каталогтағы өңір/тақырып/қызмет идентификаторларымен шектейді. Жергілікті модельге тек сұрақтың өзі,
каталог және сағат пен схема бойынша қауіпсіз нұсқаулар ғана жетеді. Диалогтағы кейінгі нақтылаушы
сұрақтар алдыңғы чат мәнмәтінін жібермей-ақ детерминирленген парсер арқылы өңделеді.
Бизнес-қызмет авторизация мен метрикалар саясатының түпкілікті қақпасы болып қала береді.

Қауіпсіз емес SQL, PII сұраулары, себеп-салдарлық мәлімдемелер және келісілмеген SLA сұраулары
инференске дейін қабылданбайды. Екіұшты сұрақтар нақтылау қажеттілігі күйін сақтайды. Күту уақытының асып кетуі,
HTTP қатесі, қысқарту, жарамсыз JSON, схеманың бұзылуы және каталогтан тыс идентификаторлар
CPU парсерінің нәтижесін қайтаруға әкеледі. Бастапқы сұрақтар, модель шығысы және жазбалар ешқашан
журналдарға, трассировкаларға немесе қате құрылымдарына қосылмайды. Модельге жасалатын HTTP сұраулары үшін
қайта бағыттаулар (redirects) мен прокси ортасының айнымалылары өшірілген.

## Тізілім

`ml/registry/analytics_intent_registry.json` файлы тіркелген модельсіз немесе псевдонимсіз жеткізіледі. Бұл
нақты өзгермейтін артефактер мен мақұлдаулар берілгенге дейін базалық алгоритмді адал түрде таңдайды.
`analytics_intent_candidates.json` файлында Qwen және Gemma ұсыныстары көрсетілген;
барлық нұсқа бекітулері, сапа бағалары және мақұлдаулар әзірге жоқ. Салмақтар жүктелмейді.
Qwen ұсынысы оның авторларының
[Qwen3-4B-Instruct-2507 модель төлқұжатымен](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507) сәйкестендіріледі.
Модель төлқұжаты RU/KK муниципалды деректерінде бағаланған жергілікті сапа дәлелі болып табылмайды.

Тіркелген әрбір модель үшін өзгермейтін модель ревизиясы, токенизатор ревизиясы,
артефакт SHA-256, орындалу ортасы (runtime) және оның нұсқасы, кванттау, промпт/схема нұсқалары және
жеке эндпоинт көрсетілуі қажет. `champion` және `rollback` рөлдері мақұлданған сұрақтар бойынша мақұлдау сілтемесін
және бағалау сілтемесін талап етеді. Синтетикалық келісімшарт есептері оларды мақұлдау үшін негіз бола алмайды.
`challenger` рөлі бағалау артефактісіне сілтей алады және тек офлайн салыстыруларда нақты сұралғанда ғана пайдаланылады.
Жүйе ядросы `champion` сұрайды.

Эндпоинттер loopback мекенжайларын, RFC1918/unique-local мекенжайларын немесе жеке бірқұрамды
қызмет атауларын қабылдайды. Бұл атауларды мақұлданған жеке желіде орналастырыңыз; оларды
сыртқы хостқа байламаңыз. Шлюз әр сұрау кезінде тізілімді қайта оқиды.
Тізілімді ауыстыруды атомарлы түрде жариялаңыз және кері қайтару үшін алдыңғы файлды сақтаңыз.

Адамның айқын растауы жұмыс қабілеттілігін (health check) және қызмет көрсететін модельдің сәйкестендіргішін
дәл тексергеннен кейін ауыстыру файлын дайындай алады:

```powershell
$env:PYTHONPATH = "services/core/src;services/inference/src"
uv run python -m pulse109_inference.analytics_registry_cli --registry active.json --action promote --approval-ref approved-change-reference --output reviewed-next.json
uv run python -m pulse109_inference.analytics_registry_cli --registry active.json --action rollback --approval-ref approved-rollback-reference --output reviewed-rollback.json
```

Командалық жол интерфейсі (CLI) файлдарды қайта жазудан бас тартады және ауыстыруды автоматты түрде жарияламайды.
Оның мақұлдау сілтемесі адам қабылдаған шешімді ғана тіркейді; команданың өзі мақұлдауды немесе модель сапасының
дәлелін жасамайды. Денсаулықты тексеру эндпоинттің модель сәйкестендіргішін тексереді, ал артефакт пен ревизияның
дұрыстығы орналастыру кезінде әлі де тексеруді талап етеді.

## Қосымша модель сервері

Қалыпты Compose стегімен және `analytics-llm` профилімен `infra/compose/docker-compose.analytics-llm.yml` файлын пайдаланыңыз.
Тексерілген vLLM бейнесін **дайджест бойынша**, бекітілген жергілікті артефакт каталогын, қызмет көрсететін модель
идентификаторын және тізілім файлын беріңіз. Бұл оверлей бір GPU пайдаланады, модель серверінің портын сыртқа жарияламайды,
артефактілерді тек оқуға арнап бекітеді, сұраныстарды журналға жазуды өшіреді және Hub/Transformers үшін офлайн режимді орнатады.
Орындалу ортасы мен кванттау бағаланған және тізілімде көрсетілген артефактіге сәйкес келуі керек.
Әдепкі бейне дайджесті немесе ойдан шығарылған модель ревизиясы жоқ.

Шлюз ресми [vLLM құрылымдалған шығыс API құжаттамасында](https://docs.vllm.ai/en/v0.21.0/features/structured_outputs/)
және оның [репозиторийдегі ағымдағы құжаттамасында](https://github.com/vllm-project/vllm/blob/main/docs/features/structured_outputs.md)
құжатталған `response_format.type=json_schema` пайдаланады. Орналастыру алдында тексерілетін орындалу ортасының
API үйлесімділігін растаңыз. Әдепкі бойынша инференс дайындығы `no-model-loaded` күйін хабарлайды; қосымша GPU сервері
қолжетімсіз болған кезде де CPU-дегі резервтік жол дайын тұрады.

## Өзгермейтін келісімшартты тексеру

```powershell
$env:PYTHONPATH = "services/core/src;services/inference/src"
uv run python -m ml.evaluation.analytics_intent_benchmark --alias baseline --output contract-report.json
uv run python -m ml.evaluation.analytics_intent_benchmark --alias challenger --registry reviewed-registry.json --output challenger-contract-report.json
```

Өзгермейтін бекітілген фикстура RU, KK, аралас, жарыстық (adversarial) және екіұшты сұрақтарды,
айқын сағатты және SHA-256 когорта бекітуін қамтиды. Есептер күтілетін өрістердің сәйкестігін,
схеманың жарамдылығын, бас тартуларды, резервтік жол метадеректерін және өлшенген жергілікті кідірісті көрсетеді.
Олар `synthetic_contract_only` деп белгіленген, `model_quality` және VRAM үшін null мәнін береді және ешқашан
RU/KK модельдерінің өлшенген сапасы, сыйымдылығы немесе енгізу дәлелі ретінде пайдаланылмауы тиіс.
Хабарланған токен саны орындалу ортасынан алынады; жоқ сандар null күйінде қалады.

B01/B06 беделді каталогтары, B08 бекітілген жеке хостинг/сәйкестендіру профилі, B09 GPU мүмкіндігі және
шынайы мақұлданған RU/KK бағалауы айқын міндетті алғышарттар болып қала береді.
Бұл нұсқаулық парсер жіктеуішті немесе іздеу модельдерін алмастырмайды.
