# Модель үміткерлері

Барлық жазбалардың күйі **Pulse 109 үшін NOT_VALIDATED**. Модель төлқұжаттарының мүмкіндіктері мен ашық көшбасшылар тақтасы (leaderboards) тексеру жүргізуге себеп қана, бірақ KK/RU/mixed муниципалды деректеріндегі сапаның, қауіпсіз калибрлеудің немесе қолайлы кідірістің дәлелі емес. Төмендегі барлық атаулар — үміткерлер; салмақ артефактерінің ешқайсысы өндірістік орындалу ортасына қосылмаған.

| Рөл | Базалық алгоритм / үміткер | Жоспарланған салыстыру |
| --- | --- | --- |
| Бағыттау | Қолданыстағы лексикалық ережелер; таңбалық+сөздік TF-IDF/LogReg; [XLM-R-base](https://huggingface.co/FacebookAI/xlm-roberta-base) | Тақырып/қызмет бойынша Top-1, Top-3, macro-F1, калибрлеу, OOD, таңдамалы қауіп және CPU p95 |
| Іздеу | PostgreSQL FTS; [Qwen3-Embedding-0.6B](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B), [BGE-M3](https://huggingface.co/BAAI/bge-m3), [multilingual-e5-large-instruct](https://huggingface.co/intfloat/multilingual-e5-large-instruct) | Recall@5/10/20, MRR, nDCG@10, гибридті ұтыс, жады және тілдер бойынша кідіріс |
| Қайта саралау | Модельдік базалық алгоритм жоқ; [Qwen3-Reranker-0.6B](https://huggingface.co/Qwen/Qwen3-Reranker-0.6B), [BGE-reranker-v2-m3](https://huggingface.co/BAAI/bge-reranker-v2-m3) | Сол үміткерлерді қайта саралау; іздеудің толық ұтысы мен p95 кідірісі |
| Дубль/оқиға | Лексикалық/гео/уақыт/актив ережелері; LogReg, содан кейін қосымша XGBoost | Жұптық AUPRC, қарау бюджеті кезіндегі дәлдік/толықтық, жалған біріктіру үлесі; автобіріктіру жоқ |
| PulseDM | BGE-M3 ортақ ұсынымы қарапайым энкодер-үміткер ретінде; Qwen3 эмбеддингтер тұқымдасы бөлек ұсыным эксперименті ретінде | Динамикалық Choice/Boolean/Score орындалу мүмкіндігі, калибрлеу және XLM-R/сызықтық базалық алгоритмдерге қарсы қауіп-қамту |
| Сыртқы құрылымдалған эталон | [Jev (TypeSafe жасаған)](https://typesafe.ai/blog/introducing-system-one-models-and-jev), қосымша құрылымдалған көптілді LLM | Құқықтық талаптар мен деректер резистенттілігі мақұлданғаннан кейін ғана офлайн эталон/мұғалім; ашық салмақтар немесе жергілікті орналастыру туралы мәлімдеме жоқ |
| Қосымша генерация | Qwen класындағы жергілікті instruct-модель, модель/нұсқа анықталады | Схемаға сай жобалар мен фактілік дұрыстық/адамның тексеруі; сыни жолда ешқашан өкілеттікке ие болмайды |

[Qwen3 эмбеддинг моделінің конфигурациясы](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B/blob/main/config.json) Qwen3 каузалды архитектурасын анықтайды. Оны PulseDM үшін бірден қолдануға болатын екібағытты энкодер деп **есептемеу керек**; ұсынымды қайта пайдалану арнайы пулинг/оқыту/бейіндеу экспериментін талап етеді. BGE-M3 алдын ала таңдалған жеңімпаз емес, энкодердің баламалы бастапқы нүктесі болып табылады.

Jev жариялаған интерфейс типтелген ықтималдық шешімдерге бағыттайды; өндірушінің мәлімдемелері Pulse деректеріндегі семантикалық дұрыстықты дәлелдемейді. Өндірушіге кіру де, азаматтардың деректерін беру де көзделмеген. Алғашқы бенчмарк мақұлданған бүркеншік аты бар снимоктармен және жергілікті жасалған болжамдармен толықтай жергілікті ортада орындала алады.
