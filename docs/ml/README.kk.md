# ML зерттеулерінің индексі

Бұл бөлім үміткерлер мен бағалау қақпаларын сипаттайды. Ол орналастырылған модель салмақтарын немесе мақұлданған өндірістік сапаны **сипаттамайды**.

- [Стратегия](MODEL_STRATEGY.kk.md): ағымдағы жол және үш үміткер бағыты.
- [Үміткерлер](MODEL_CANDIDATES.kk.md): модель идентификаторлары, рөлдер және таңдауға дейін қажет дәлелдер.
- [PulseDM дизайны](PULSEDM_DESIGN.kk.md): зерттеу интерфейсі және ықтимал архитектура.
- [Бағалау хаттамасы](EVALUATION_PROTOCOL.kk.md): салыстырмалы KK/RU/mixed бөлулері мен метрикалар.
- [Деректерге қойылатын талаптар](DATA_REQUIREMENTS.kk.md): деректердің шығу тегі, құпиялық және ақпарат ағып кетуінің кедергілері.
- [Модельдерді басқару](MODEL_GOVERNANCE.kk.md): модель төлқұжаттары, мақұлдау және кері қайтару.
- [Модель төлқұжатының үлгісі](MODEL_CARD_TEMPLATE.kk.md).

Офлайн салыстырудың орындалатын шекарасы — [`ml/evaluation/candidate_compare.py`](../../ml/evaluation/candidate_compare.py); [эксперимент нұсқаулары](../../experiments/README.kk.md) оның кіріс келісімшартын көрсетеді. Синтетикалық базалық алгоритм мен іздеу бойынша қолданыстағы есептер сынақ деректерінің диагностикасы ретінде қалады.
