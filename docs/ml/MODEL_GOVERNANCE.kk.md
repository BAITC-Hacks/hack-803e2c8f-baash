# Модельдерді басқару

PulseDM және әр аталған сыртқы/жергілікті үміткер **NOT_VALIDATED** күйінен бастайды. Синтетикалық бағалаушыдан өту контракт пен метрика коды орындалатынын дәлелдейді, болжамның пайдалы екенін емес. Нақты бекітілген holdout тәуелсіз тексеру мен қолтаңбалы шығарылым шешіміне дейін **EVALUATION_ONLY** дәлелін береді.

| Кезең | Міндетті жазба | Өкілетті тарап |
| --- | --- | --- |
| Деректер | Құқықтық негіз, сақтау, тұлғасыздандыру тексеруі, снимок хеші, эталон белгі саясаты, уақыт/топ бойынша бөлу | Дерек иесі және құпиялықты бекіту |
| Модель | Бекітілген артефакт/тәуелділік хеші, паспорт, prompt/сұрақ және таксономия нұсқалары, оқыту/калибрлеу шығу тегі | ML reviewer |
| Бағалау | KK/RU/mixed және өңір сандары, қате талдауы, калибрлеу/OOD, risk-coverage, кідіріс, ереже/сызықтық baseline-пен салыстыру | Тәуелсіз техникалық тексеру |
| Жұмыс сынағы | Тек shadow/ұсыныс мониторингі, оператор түзетулері және ақау талдауы, кері қайтару/резервтік жол сынағы | Өнім және пайдалану иелері |
| Белсендіру | Бекітілген қолтаңбалы өңірлік конфигурация, адам басқаратын Decision Gateway, айқын енгізу/кері қайтару жоспары | Уәкілетті өңірлік басқару |

Офлайн метрика модельді не саясатты өздігінен іске қоспайды. Белгісіз сәйкестіктер, бекітілмеген саясат немесе нұсқа айырмасы тексеру/қолжетімсіз күйін береді. Тақырып/қызмет ұсынысы мен дубль дәлелдері тағайындауға, оқиғаны merge етуге, басымдық өзгертуге не жабуға рұқсат бермейді. Модель істен шықса, өтінішті жоғалтпай lexical/CPU/қолмен жолдарына ауысады.

Есептер дерек түрін, санын және шектеулерін көрсетуі тиіс. Синтетикалық нәтижелер өндірістік модель сапасының панельдеріне кірмейді. Ұсыныстар мен оператор шешімдерінің өзгермейтін аудитін/шығу тегін сақтаңыз; тіл/өңір әділдігін бақылап, сенімділік калибрлеуі не қамту нашарласа әрекет етіңіз. Кері қайтару дерекқор санауышын азайтпай, қолтаңбалы control plane арқылы бұрын бекітілген модель/саясатты қайтарады.

Әр *іске асырылған* үміткерге [паспорт үлгісін](MODEL_CARD_TEMPLATE.kk.md) қолданыңыз. Тек [MODEL_CANDIDATES](MODEL_CANDIDATES.kk.md) ішінде аталу енгізуді білдіретін паспорт жасамайды.
