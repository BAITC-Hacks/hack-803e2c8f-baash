# Текущий статус Pulse 109

Источник истины о продукте, сверенный 1 октября 2026 года с исполняемой ревизией `135680a`, контрактами и исполняемым кодом. «Работает» означает реализованный путь с проверками, а не сертификацию для промышленной эксплуатации. Публичный [demo](https://baash.govtech-kz.com/demo) использует синтетические данные ALA; API, PostgreSQL, миграции, audit, outbox и worker настоящие.

Словарь: **✅ Работает в исполняемом контуре** · **🟡 Частично / базовый алгоритм / демо** · **🔬 Исследовательский результат** · **⛔ Внешний блокер**. Статус может отличаться для механики и её бизнес-валидации.

## Свежесть Golden World

Водный сценарий обновлён **1 октября 2026, 21:13 Asia/Qyzylorda (16:13 UTC)**. Резервная копия проверена перед записью; прежние обращения и даты сохранены. В БД 121 календарный день истории и шесть новых водных сообщений. Radar за шесть часов, Ask Pulse RU/KK, экспорт и прогнозы 30/60/90 прошли.

Свежесть относится к указанному времени проверки. Перед следующим показом оператор запускает `scripts/demo_refresh.py` для `pulse109-final` по [PUBLIC_DEPLOYMENT](../infra/runbooks/PUBLIC_DEPLOYMENT.md); обычный `seed` сохраняет существующие даты.
