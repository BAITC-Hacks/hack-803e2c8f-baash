## 2. Шешілген негізгі кедергілер (P0)

1. **Тіркеменің қабылдау тігісі [ШЕШІЛДІ]**:
   - `manual_path/router.py` және `postgres_path.py` `POST /v1/requests/{id}/attachments` және `GET /v1/requests/{id}/attachments` орындалды. `appeals.attachment_ref` дейін сақталмас бұрын, файл сигнатурасын MIME тексеруін, орындалатын қабылдамауды және зиянды бағдарламаны сканерлеуді жүзеге асырады.
2. **Өтініш бойынша кезек тізімі (`GET /v1/requests`) [ШЕШІЛДІ]**:
   - Күйді сүзуді, шекті/курсорды беттеуді және аймақты оқшаулауды қолдайтын беттелген `GET /v1/requests` соңғы нүкте қосылды. Web frontend (`page.tsx`) енді серверден тікелей өтініштерді ағынмен жібереді.
3. **Басқару қабаты маршрутизаторын іске қосу 503 қатесі [ШЕШІЛДІ]**:
   - Сымды `verifier` `main.py` ішіндегі `create_control_plane_router(bundle_repository, verifier=verifier)` ішіне жалғаңыз. Буманы белсэмбеддинг қолтаңбаны тексеру арқылы HTTP ішінде жұмыс істейді.
4. **Ажыратылған құпиялылық қызметі [ШЕШІЛДІ]**:
   - `pulse109.privacy.create_privacy_router` `main.py` ішінде `/v1/privacy` нүктесінде аутентификацияланған ажыратымдылықпен және қол жеткізу аудиторияларымен орнатылған.
5. **Жадтағы тұрақсыз ескерту күйі [ШЕШІЛДІ]**:
   - `PostgresAlertStore` `analytics.alert` және `analytics.alert_review` ішінде тұрақты ескертулер мен шолуларды сақтау үшін `psycopg.sql` көмегімен іске қосылды, тұрақсыз жадтағы жадты ауыстырды.

## 3. Шешілген жоғары бақосылғанлықтағы кемшіліктер (P1)

1. **Эфемерлік суретті қайталау [ШЕШІЛДІ]**:
   - `FileSnapshotStore` қосылымын `main.py` ішіндегі `PostgresReplayRepository` ұяшығына жалғап, процесті қайта іске қосу кезінде дискіге replay snapshot көшірмесін сақтайды.
2. **Адаптердің кешігуінің жалған позитивтері [ШЕШІЛДІ]**:
   - Тек адаптерге бағытталған оқиға түрлерін (`appeal.assigned.v1`, `appeal.reassigned.v1`, `appeal.status.changed.v1`) тексеру үшін сүзілген `AdapterLagDetector`.
3. **Жазықтықтың монотонды кері қайтару ағынын басқару [ШЕШІЛДІ]**:
   - `pulse109.control_plane.bundles` ішінде `create_rollback_bundle` және `cli.py` ішінде `pulse109-bundle rollback` командасы қосылды., мақсатты белгілі-жақсы манифесттерге қайта қол қою кезінде монотонды дәйектілікті қауіпсіз түрде ілгерілету.
4. **Карантинге жатқызылған/инфекцияланған дәлелдемелерді қабылдамау [ШЕШІЛДІ]**:
   - Жаңартылған `outcomes/postgres.py` алдын ала тексеру және растау `data_classification` бастап `appeals.attachment_ref` ішінен тексеру және HTTP 422 `evidence_quarantined` арқылы қауіпсіздік жалаушасы бар немесе карантинге қойылған файлдарды қабылдамау. Атомды жабу алдында растау кезінде қайта тексерілді.

## 5. Сыртқы кедергілер

Бұл мәселелерді ресми бекітілген үкімет немесе муниципалды серіктес артефактілерсіз шешу мүмкін емес:
- **B01 (Ұлттық манифест және қамту)**: 20 аймақтың 13-інде бастапқы деректер жиыны жоқ.
- **B02 (Raw Citizen Text/Audio)**: Барлық қолжетімді аймақтық үзінділерде шикі азамат мәтіні жоқ; NLP дәл реттеуі бұғатталған.
- **B06 (Бекіттік таксономия және SLA Саясат)**: Муниципалды SLA ережелер мен санат ағаштары заңды түрде ратификацияланбаған.
- **B07 (Аймақтық CRM sandbox және тіркелгі деректері)**: Тікелей адаптер сынағы аймақтық 109 соңғы нүктеге кіруді қажет етеді.
- **B08 (Өндіріс OIDC идентификациялық провайдер)**: Орналасу инфрақұрылымы күтілетін муниципалды SSO соңғы нүктелері (Keycloak/IdP).
- **B10 (Заңды негіз және сақтау кестесі)**: Өндіріс қоймаларында нақты азамат PII сақталмас бұрын, сақтау кестелері ресімделуі керек.

## 6. Алдыңғы есептердегі жалған толтыру талаптары

- **Шағым:** «Тіркемені қабылдау үшін қауіпсіздікті күшейту: екілік файл сигнатурасын тексеру, орындалатын қабылдамау және қосылатын зиянды бағдарлама сканері».
  - **Шындық:** Функциялар мен сынақтар болған кезде, олар HTTP API желісінен толығымен ажыратылды. Ешбір оператор немесе азамат файлды жүктей алмады.
- **Шағым:** "Басқару қабаты HTTP API: белсенді және белсендірілген соңғы нүктелер қосылды."
  - **Нақтылық:** HTTP 503 арқылы белсэмбеддинг әрқашан орындалмады, себебі тексеруші `main.py` ішінде ешқашан жасалмаған.
- **Шағым:** "Құпиялылық анықтамалық шекарасы және PII қолжетімділік аудиті."
  - **Шындық:** Маршрутизатор жасалмаған немесе орнатылмаған; қызмет бірлік сынақтарынан тыс пайдаланылмаған.
- **Шағым:** "Оператор UI: жұмыс кеңістігіне тікелей қосылған арнайы интерактивті панельдер."
  - **Шындық:** `page.tsx` ішіндегі кезек жалған идентификаторларға қатты кодталған, себебі `GET /v1/requests` жоқ.

## 7. Сақтауға тұрарлық архитектура шешімдері

1. **PostgreSQL** ішіндегі деректердің бірыңғай негізгі көзі: домен транзакциялары, аудит оқиғалары, outbox-тың жазбалары және идемпотенттілік нәтижелері бір атомдық дерекқор транзакцияларында орындалады.
2. **Дерминистік кері қайтаруға қарсы монотондылық**: қол қойылған конфигурация конверттері кездейсоқ төмендетуге немесе конфигурацияны рұқсатсыз өзгертуге жол бермейді.
3. **Сәтсіз жабылған құпиялылық кепілдіктері**: Журналдар, бақылау атрибуттары және метрикалық белгілер бос мәтінді және өңделмеген азамат идентификаторларын қатаң түрде қабылдамайды.
4. **Адамның AI шекарасы**: ML және аналитика ешқашан өтініштерды өздігінен бағыттамайды, оқиғаларды біріктірмейді немесе сыртқы әрекеттерді орындамайды.
