# Pulse 109 жүргізуші карточкасы

Дайындаудың нақты командасы және толық жол: [Golden Demo](GOLDEN_DEMO.kk.md). Жария кіру: [demo](https://baash.govtech-kz.com/demo); жаңа су сканерлеуіне өзекті әлем қажет, [VPS runbook](../infra/runbooks/PUBLIC_DEPLOYMENT.kk.md) қараңыз. Жергілікті көрсетілім үшін `.\demo.ps1 prepare` орындап, `PULSE 109 DEMO READY` жолын күтіңіз. `http://localhost:3000/demo?presenter=1` ашыңыз.

| Қадам | Әрекет | Не айту керек |
| --- | --- | --- |
| 1. Өтініш | Су мысалын толтыру, мәтінді тексеру, қолмен жіберу | «Азамат қалыпты API арқылы жаңа өтініш жібереді. Деректер ойдан шығарылған.» |
| 2. Оператор | Жасалған ID-ді кезектен ашу, ұсыныс сұрау, растау | «Лексикалық базалық алгоритм бағыт ұсынады; адам шешім қабылдайды. Көрсетілген бағалар баламаларды реттейді, модель дәлдігін өлшемейді.» |
| 3. Radar | Operations Center-ге оралу, алты сағатты сканерлеу, кластерді ашу | «Жаңа хабарламалар уақыты мен орны бойынша жақын. Жүйе себебін мәлімдемейді.» |
| 4. War Room | Кластерден оқиға жасау, footprint және advisory көрсету | «Әр өтініш өз ID мен тарихын сақтады. Оқиға қызметтердің жұмысын байланыстырады.» |
| 5. Ask Pulse | Жеті күн туралы сұрақты, есептеуді, бастапқы өтініштерді, PDF/Excel және болжамды көрсету | «Жауап PostgreSQL жазбаларынан жасалады және бастапқы дерекке дейін ашылады. Болжам синтетикалық тарихқа негізделген.» |

Демоны ұлттық қамту деп атамаңыз: сценарий ALA үшін егжей-тегжейлі жасалған. Тарихи экспорттар 20 өңірдің 7-еуін қамтиды. Қазіргі демода 5 тақырып тобы және 4 синтетикалық бағыттау тақырыбы бар. Нақты өңірлік CRM, ресми таксономия және тексерілген ML дәлдігі сыртқы кедергілер болып қала береді.

ML істен шығуы туралы сұралса, кезектегі қолмен шешімді көрсетіңіз: өтініш жасау, бағыттау, мәртебе және аудит inference-сіз жұмыс істейді. Модельді тексеру туралы сұралса, Replay Lab ашып, синтетикалық жағдайлар сапаны бағалаудан шығарылатынын түсіндіріңіз.
