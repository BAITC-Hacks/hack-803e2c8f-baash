# Локальное демо без Docker

Полностью локальный маршрут ведущего запускается из корня репозитория:

```powershell
pnpm install
pnpm demo:mock
```

Откройте [http://localhost:3000/demo](http://localhost:3000/demo). Команда
запускает только Next.js; Docker, FastAPI, PostgreSQL, worker, внешняя сеть и
учётные данные не нужны. Страница сама открывает панель ведущего.

Все `/api/core/*` запросы со страницы `/demo` обслуживаются локальным mock
runtime, пока задан `PULSE109_DEMO_MOCKS=1`. Остальные страницы и обычный запуск
сохраняют прежнюю прокси-интеграцию. Локальные данные создаются при первом
запросе, изменяются действиями оператора и живут только в памяти процесса.
Кнопка «Сбросить демо» возвращает исходный сценарий; перезапуск Next.js тоже
сбрасывает данные.

Обращения, личности, каталог служб, Radar, история, решения, инциденты,
маршрутизация, очередь доставки, аналитика, отчёты и скачиваемые PDF/XLSX здесь
синтетические. Действия меняют только локальную симуляцию. Внешняя доставка не
выполняется, модельные метрики не заявляются, а synthetic replay исключён из
оценки качества. Метка `MOCK DEMO · СИМУЛЯЦИЯ` остаётся видимой в интерфейсе.

Команду остановите `Ctrl+C`. Чтобы вернуться к PostgreSQL-профилю демо,
используйте [обычный runbook](DEMO_RUNBOOK.md); mock runtime в нём не включён.
