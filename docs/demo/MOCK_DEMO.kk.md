# Docker-сыз жергілікті демо

Толық жергілікті жүргізуші жолын репозиторий түбірінен іске қосыңыз:

```powershell
pnpm install
pnpm demo:mock
```

[http://localhost:3000/demo](http://localhost:3000/demo) ашыңыз. Команда тек Next.js іске қосады; Docker, FastAPI, PostgreSQL, worker, сыртқы желі және credentials қажет емес. Дайындалған сценарий үшін [http://localhost:3000/demo?presenter=1](http://localhost:3000/demo?presenter=1) ашыңыз: ол өтініш мәтіні толтырылған форманың бірінші қадамын бірден көрсетеді.

`PULSE109_DEMO_MOCKS=1` берілген кезде `/demo` бетіндегі барлық `/api/core/*` сұрауларына жергілікті mock runtime жауап береді. Басқа беттер мен қалыпты іске қосу бұрынғы proxy интеграциясын сақтайды. Жергілікті деректер алғашқы сұрауда жасалады, оператор әрекеттерімен өзгереді және тек процесс жадында тұрады. «Демоны қалпына келтіру» батырмасы бастапқы сценарийді қайтарады; Next.js қайта іске қосылса да деректер қалпына келеді.

«После ремонта вода стала мутной и появился металлический запах.» мәтіні автоматты толтырылады. Ұқсас мәселелерді тексеру су сапасына қатысты алты ашық mock өтініштен үміткерлерді алдын ала жүктейді; соңғы қадамда оларды қолмен растау қажет. Сценарийге кіру ештеңені жібермейді және біріктірмейді. Ctrl+Shift+D жүргізуші панелін жасырады.

Бұл жерде өтініштер, тұлғалар, қызметтер каталогы, Radar, тарих, шешімдер, оқиғалар, бағыттау, жеткізу кезегі, аналитика, есептер және жүктелетін PDF/XLSX файлдары синтетикалық. Әрекеттер тек жергілікті симуляцияны өзгертеді. Сыртқы жеткізу орындалмайды, модель метрикалары мәлімделмейді, ал synthetic replay сапаны бағалаудан шығарылады. Интерфейсте `MOCK DEMO · СИМУЛЯЦИЯ` белгісі көрініп тұрады.

Команданы `Ctrl+C` арқылы тоқтатыңыз. PostgreSQL демо профиліне оралу үшін [қалыпты runbook](DEMO_RUNBOOK.kk.md) пайдаланыңыз; онда mock runtime қосылмайды.
