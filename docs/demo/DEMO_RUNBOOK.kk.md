# Pulse 109: іске қосу және демонстрация бағыты

Көрсетілімнің негізгі бағыты — [Golden Demo](GOLDEN_DEMO.kk.md). Ол бір жаңа өтінішті оператор шешімімен, Radar, Incident War Room және Ask Pulse құралдарымен байланыстырады. Деректер ойдан шығарылған; FastAPI, PostgreSQL, миграциялар, аудит, outbox, worker және Next.js кәдімгі қолданба кодымен жұмыс істейді. Сыртқы жеткізу өңірлік CRM-ге емес, replay адаптеріне барады.

## Жария көрсетілім

[Landing](https://baash.govtech-kz.com/) → [demo](https://baash.govtech-kz.com/demo). Бұл — браузерлік mock емес, PostgreSQL негізіндегі профиль. Хост операциялары [PUBLIC_DEPLOYMENT](../../infra/runbooks/PUBLIC_DEPLOYMENT.kk.md) ішінде сипатталған. Төмендегі жергілікті `prepare/verify/reset` VPS `pulse109-final`-ды емес, `pulse109-demo` жобасын басқарады. Жаңа Radar сканерлеуінің алдында су сценарийінің балғындығын тексеріңіз: ескі seed уақыт таңбаларын сақтайды.

## Жергілікті дайындық

Linux қозғалтқышы жұмыс істеп тұрған Docker Desktop, Python 3.10–3.13, `uv` және бос 3000, 5432 және 8080–8084 порттары қажет. Репозиторий түбірінен:

```powershell
uv sync --all-groups --frozen
.\demo.ps1 prepare
```

macOS/Linux үшін: `uv run python scripts/demo_runtime.py prepare`. Команда бөлек `pulse109-demo` Compose жобасын көтереді, API walkthrough орындайды, тек осы демо-жобаның томдарын жояды, таза әлем жасайды және оны API арқылы тексереді. `PULSE 109 DEMO READY` жолын күтіңіз. Егер ол болмаса, демо дайындалмаған.

Дайындықтан кейін [интерфейсті](http://localhost:3000/demo) ашыңыз. Жүргізуші режимі [?presenter=1](http://localhost:3000/demo?presenter=1) мекенжайы бойынша қолжетімді. Алдын ала орнату түймесі тек ойдан шығарылған өтінішті толтырады; жіберу және одан арғы шешімдер адамның еншісінде қалады. Қайта көрсетпес бұрын `prepare` командасын қайта орындаңыз.

## Егер қазылар алқасы толығырақ сұраса

- **Операциялық сенімділік:** кезекте қолмен тағайындауды, outbox және worker арқылы `Queued → Delivered` күйін, содан кейін уақыт шкаласы мен аудит журналын көрсетіңіз. Replay адаптерінің жауабы синтетикалық.
- **Жабу және дәлелдер:** дайындалған өтініште алдын ала жүктелген SHA-256 evidence reference, preflight және оператордың растауын көрсетіңіз. Демо-сканерді өндірістік антивирус деп атамаңыз.
- **Data Lab:** уақыт сапасы көрсеткішін және бизнес-уақыты жоқ жазбалар тізімін ашыңыз. Мұндай жазбалар ойдан шығарылған уақыт таңбасын алмайды.
- **Қазақ тіліндегі Ask Pulse:** `Соңғы 7 күнде өтініштер саны қалай өзгерді?` деп сұраңыз; график, қамту және нәтиженің шығу тегін көрсетіңіз.
- **Replay Lab:** синтетикалық жазбалар модель сапасын бағалаудан шығарылған. Нөлдік бағалау таңдамасы «сәтті» көрсеткішке айналмай, көрініп тұруы керек.
- **ML резервтік жолы:** жұмыс істеп тұрған орындалу ортасы lexical CPU бағыттауын және резервтік іздеуді (fallback retrieval) пайдаланады. Бейімделген жіктеуіш және азаматтар мәтінінің embeddings көрсетілім үшін расталмаған; inference тоқтатылған кезде қолмен жұмыс жолы қолжетімді болып қала береді.

## Операциялық командалар

| Команда | Мақсаты |
| -------------------- | ------------------------------------------------------------------ |
| `.\demo.ps1 prepare` | Толық өту, таза seed және Golden Demo тексеруі. |
| `.\demo.ps1 verify` | Базалық API walkthrough, содан кейін таза seed. |
| `.\demo.ps1 status` | Контейнерлердің күйі. |
| `.\demo.ps1 down` | Демо-томдарды сақтай отырып тоқтату. |
| `.\demo.ps1 reset` | Тек `pulse109-demo` томдарын жою; одан кейін `prepare` қажет. |

`PULSE109_DEMO_NOW` қайталанатын тесттер үшін пайдаланылуы мүмкін, бірақ тірі Radar жүйелік уақытты алады. Егер бекітілген сағат ағымдағы уақыттан бес минуттан артық алшақтаса, `prepare` оны қабылдамайды. Қайталанған `seed` бұрын жасалған шешімдерді сақтайды; бірдей бастапқы әлем үшін `prepare` пайдаланыңыз.

## Көрсетілім шекаралары

- Сценарий Алматы үшін егжей-тегжейлі жасалған. Синтетикалық қала 20 өңірді қамтуды немесе ұлттық статистиканы растамайды.
- Демо-каталогта төрт синтетикалық бағыттау тақырыбы, ал фондық жазбаларда бес тақырып тобы бар. Он тақырып туралы талап ашық күйінде қалады.
- Өндірістік сәйкестендіру провайдері, бекітілген таксономия/SLA, құқықтық негіздер және өңірлік API жоқ. [Ағымдағы күй](../submission/FEATURE_STATUS.kk.md) мен [сыртқы кедергілерді](../governance/DECISIONS_AND_BLOCKERS.kk.md) қараңыз.
- Егер PostgreSQL қолжетімсіз болса, readiness және seed тоқтайды. In-memory repository демо PostgreSQL-ді алмастырмайды.
