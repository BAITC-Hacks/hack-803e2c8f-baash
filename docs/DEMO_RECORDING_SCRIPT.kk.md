# Екі минуттық демоны жазу

Қорытынды бейненің негізгі көзі — жария PostgreSQL-backed [demo](https://baash.govtech-kz.com/demo). Жол [Golden Demo](GOLDEN_DEMO.kk.md) сценарийіне сәйкес. API/БД қалыпты, әлем дайын және су сценарийі өзекті болуы қажет; лендингтің қолжетімділігі мұны өздігінен дәлелдемейді. Жазбас бұрын [deployment runbook](../infra/runbooks/PUBLIC_DEPLOYMENT.kk.md) тексеріңіз.

Қайталаудан кейін браузерді қолмен жазыңыз. Көрсетілім нақты процестер мен синтетикалық ALA жазбаларын қамтиды; ол Алматы статистикасын немесе қосылған өңірлік CRM-ді көрсетпейді. Жария стендтің автоматты өтуіне нақты уақыт уәде етпеңіз.

| --- | --- | --- |

| 00:08–00:24 | Қабылдау: water preset, ұқсас ашық мәселелер, қолмен жіберу | «Жөндеуден кейін су лайланды. Pulse ұқсас сигналдарды көрсетеді, жіберуді адам растайды.» |
| 00:24–00:45 | Кезектегі жасалған ID: ұсыныс сұрау және растау | «Жүйе тақырып, қызмет және басымдық ұсынады. Бағытты оператор бекітеді.» |

Ask Pulse нәтижесін, KPI және графикті бір кадрда ұстаңыз. Жауап баяу болса, көріністі ұзартыңыз; монтажды кідіріс кепілдігі ретінде көрсетпеңіз. Өзекті Radar үшін жаңа fixture timestamps қажет: `seed` қайта орындау оларды жылжытпайды. Сақталған кластерді сақталған нәтиже деп нақты атап, бөлек көрсетуге болады.

## Жергілікті автоматты көмекші: бөлек mock сценарий

`scripts/record_demo.py` қазір «Похожее обращение 1» сияқты бекітілген mock белгілерін күтеді. Оның 117 секундтық жолы [жергілікті симуляция](MOCK_DEMO.kk.md) үшін тексерілген; жария PostgreSQL демосымен үйлесімділігі расталмаған. `--base-url` болуы бұл сценарий VPS-те автоматты тексерілді дегенді білдірмейді.

Тек дайындалған жергілікті симуляция үшін, Python Playwright/Chromium орнатылғанда:

```powershell
python scripts/record_demo.py --output "$env:USERPROFILE\Videos\Pulse109-demo.webm" --duration 117
```

Көмекші жұмыс үстелін емес, бетті headless Chromium 1920×1080 арқылы жазады. Бұл бейне браузер симуляциясы деп белгіленуге тиіс және жария PostgreSQL демосының дәлелін алмастырмайды. Қорытынды тапсыру үшін нақты жария жолды жазу ұсынылады.
