# Pulse 109 ағымдағы күйі

Өнім туралы ақиқат дереккөзі, 2026 жылғы 1 қазанда `135680a` орындалатын ревизиясымен, келісімшарттармен және орындалатын кодпен салыстырылған. «Жұмыс істейді» өндірістік пайдалануға сертификаттауды емес, тексерулері бар іске асырылған жолды білдіреді. Жария [demo](https://baash.govtech-kz.com/demo) синтетикалық ALA деректерін пайдаланады; API, PostgreSQL, миграциялар, аудит, outbox және worker нақты.

Сөздік: **✅ Орындалу ортасында жұмыс істейді** · **🟡 Ішінара / базалық алгоритм / демо** · **🔬 Зерттеу нәтижесі** · **⛔ Сыртқы кедергі**. Мәртебе механика мен оның бизнес-валидациясы үшін әртүрлі болуы мүмкін.

## Тексерулер және шығарылым шарттары

`135680a` нұсқасындағы [CI 36889724226](https://github.com/BAITC-Hacks/hack-803e2c8f-baash/actions/runs/36889724226) барлық төрт тапсырмасы өтті: quality, container-smoke, demo-profile-smoke және security-supply-chain. Python/Node audits, gitleaks, Trivy және SBOM орындалды. Нақты нәтижелер, нұсқалар мен командалар [DEVELOPMENT](../development/DEVELOPMENT.kk.md) құжатында жинақталған.

Жаңа тәуелділіктер мен API image CI арқылы тексерілді; жұмыс істеп тұрған VPS бұрынғы образдарды сақтайды. Golden World деректерін жаңарту нақты API арқылы бөлек тексерілді.

## Golden World балғындығы

Су сценарийі **2026 жылғы 1 қазан, 21:13 Asia/Qyzylorda (16:13 UTC)** уақытында жаңартылды. Жазу алдында резервтік көшірме тексерілді; бұрынғы өтініштер мен күндер сақталды. ДҚ-да 121 күнтізбелік күн тарихы және алты жаңа су хабарламасы бар. Алты сағаттық Radar, Ask Pulse RU/KK, экспорт және 30/60/90 күндік болжамдар өтті.

Балғындық көрсетілген тексеру уақытына қатысты. Келесі көрсетілім алдында оператор [PUBLIC_DEPLOYMENT](../../infra/runbooks/PUBLIC_DEPLOYMENT.kk.md) нұсқаулығы бойынша `pulse109-final` үшін `scripts/demo_refresh.py` сценарийін іске қосады; әдеттегі `seed` бар күндерді сақтайды.

## Сыртқы кедергілер

`B01` манифест және қалған өңірлер · `B02` шешімге дейінгі шикі мәтін · `B03` өрістер мен уақыт мәні · `B04` көшірмелерді белгілеу · `B05` түзетулер тарихы · `B06` таксономия/SLA · `B07` өңірлік API · `B08` сәйкестендіру және желі · `B09` GPU · `B10` құпиялылық, құқықтық негіздер және сақтау мерзімдері. Толығырақ: [DECISIONS_AND_BLOCKERS](../governance/DECISIONS_AND_BLOCKERS.kk.md).

ТТ-мен барлық алшақтықтардың толық тізімі, соның ішінде ML бойынша ішкі жұмыс — [competition audit](../review/COMPETITION_AUDIT_2026-09-29.kk.md). Синтетикалық әлем де, сыртқы кедергі де жабылған талапқа айналмайды.
