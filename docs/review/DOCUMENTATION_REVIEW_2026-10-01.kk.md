# GovTech Camp тапсыру алдындағы құжаттаманы тексеру

> Stabilization-ге дейінгі `91fd220` құжаттамалық тексеруінің тарихи есебі. Security CI-ді кейінгі түзету және Golden World-ты жаңарту [DEVELOPMENT](../DEVELOPMENT.kk.md) және [PUBLIC_DEPLOYMENT](../../infra/runbooks/PUBLIC_DEPLOYMENT.kk.md) құжаттарында сипатталған. Төмендегі ашық әрекеттер осы есеп дайындалған кездегі күйді көрсетеді.

Күні: **2026 жылғы 1 қазан**. Тексеру базасы: ресми `main`, `e494390`; 12 қыркүйектегі алғашқы `d199e16` коммитінен бастап Git ауқымы. Орыс тіліндегі README — негізгі тапсыру құжаты, EN/KK — баламалары. Бұл өту арқылы өнімдік код, орындалатын келісім-шарттар, миграциялар, тәуелділіктер және орналастыру конфигурациясы өзгертілген жоқ.

## Қамту

`docs/archive` сыртындағы барлық 76 Markdown файлы тексерілді, соның ішінде түбірлік құжаттар, нұсқаулықтар, docs/features/architecture/ml/security/review, contracts/ADR, adapters, infra/runbooks/helm/dashboards, datasets/evaluation/training, experiments, load/resilience және migration README-лері бар. Түбірдегі тарихи жоспарлар анық белгіленген. Мұрағаттағы тоғыз Markdown сілтемелерді тексеруге қосылды; олардың мазмұны ағымдағы мәртебе ретінде қайта жазылған жоқ. README.kk және осы есеп қосылды.

Файлдардың толық қайталанатын тізімі: `git ls-files '*.md'`. Әрбір белсенді кіріс құжатының санаттары, мақсаты және тілі [құжаттама индексінде](../README.kk.md) көрсетілген.

## Дәйектер дереккөздері

- Орындалатын шекаралар: [OpenAPI](../../contracts/openapi.yaml), канондық схема және оқиғалар; intake/manual_path/incidents/discovery/analytics/replay/security модульдері, inference engine және retrieval provider.
- Деректер: [DQ report](../../data/reports/regional-csv-dq-report.json), жасырын корпус манифесі және зерттеу есептері; өңделмеген деректер тарихтан қалпына келтірілген жоқ.
- Авторлық: толық Git тарихы/shortlog, merge-коммиттер және файл өзгерістері; GitHub API Arseniiiii-ai және Shyngyskhan-333 аккаунттарын растады. Толық есімдер/капитан рөлі коммиттер санынан емес, бастапқы журналдан алынды.
- `e494390` нұсқасындағы CI: [36876998829](https://github.com/BAITC-Hacks/hack-803e2c8f-baash/actions/runs/36876998829): quality/container/demo сәтті өтті; қауіпсіздік аудиті қатемен аяқталды. Нақты нәтижелер — [DEVELOPMENT](../DEVELOPMENT.kk.md).
- Орналастыру: 1 қазандағы Compose, образдар, қайта іске қосу саясаты, порттар және HTTP GET тексерісі; web `22d89e7`, ұйымдастырушылардың HTTPS, жергілікті нысандар, PostgreSQL ready. API оқу 120 күндік тарихты және су хабарламаларының күні 30 қыркүйек екенін көрсетті.

## Тілдер және команда үлесін растау

Қазылар алқасы үшін негізгі орыс тіліндегі құжаттар: README, индекс, журнал/тарих/мәртебе, көрсетілім сценарийлері, архитектура, мүмкіндіктерге шолу, кедергілер, қабылдау матрицасы және жария орналастыру. EN/KK README дәл сол шектеулерді сақтайды.

API/оқиғалар/ADR сипаттамалары және егжей-тегжейлі техникалық мүмкіндіктер беттері, ML/қауіпсіздік/пайдалану бойынша терең материалдар, тесттер/деректер/модель паспорттары бойынша нұсқаулықтар мен тарихи шешімдер ағылшын тілінде қалдырылды. Олардың тұтынушысы — нақты идентификаторлар мен командаларды тексеретін әзірлеуші; индекс тіл мен мақсатты көрсетеді. Әрбір техникалық жазбаның үш көшірмесі жасалған жоқ.

Arsen/Baktiyar/Shyngyskhan: нақты код өзгерістері Git арқылы расталған. Aspandiyar: бастапқы журнал бойынша капитан/архитектура/қорғау; апталық коммиттер тағайындалмайды. Бірінші апта және 11 қыркүйектегі көрсетілім құжатпен расталған, алғашқы Git өзгерістері — 12 қыркүйек. Толық есімдер командалық дереккөз бойынша сақталды; Git-тегі жазылу нұсқалары ескерілген.

## Осы тексеру барысындағы тексерістер

Жергілікті сілтемелер мен якорлар барлық 87 Markdown файлында тексерілді. Сыртқы сілтемелер HTTP-сұраныстар және GitHub CLI арқылы тексерілді: 16-сы жария түрде қолжетімді, Actions-қа 22 сілтеме авторизациядан кейін қолжетімді; localhost/example әдейі өткізіп жіберілді. Қолжетімсіз тарихи run `34685618121` мәтіндік белгімен ауыстырылды. Ескірген тұжырымдар, мәртебелер, тармақтар және сапа туралы мәлімдемелер тексерілді. Барлық 31 өзгертілген/жаңа Markdown Prettier тексеруінен өтті. `git diff --check` сәтті өтті; `git status` тексеруі өзгерістердің тек құжаттамаға қатысты екенін растады. Commit SHA-ға 39 сілтеме тексерілді — барлығы бар. Жергілікті сілтемелер/якорлар: 297, қателер: 0. Тест сандары көрсетілген CI-ден алынды, backend қайта іске қосылған жоқ.

## Көрсетілім және тапсыру алдында ашық қалған мәселелер

1. Осалдықтары бар тәуелділіктер бөлек түзетуді және жасыл қайталау gate-ін талап етеді; құжаттамалық тексеру осалдықтарды жоймайды.
2. Жаңа жария су сканерлеуі үшін сақтық көшірмесі және дұрыс Compose жобасы бар синтетикалық әлемді келісілген түрде жаңарту қажет. Сайт қолжетімді, бірақ су сценарийінің жаңалығын тексеру өткен жоқ.
3. Квота жұмсақ лимитке жақын; жазу/жаңарту алдында сыйымдылықты тексеруді қайталаңыз. Қолжетімділік мерзімі мен SLA уәде етілмейді.
4. B01–B10 және ішкі ML алшақтықтары [жарыс аудитінде](COMPETITION_AUDIT_2026-09-29.kk.md) көрініп тұр.

Бірінші аптадағы расталмаған жеке міндеттер шынайы тапсыру үшін қажет емес: кесте дереккөзді және жеке бөліністің жоқтығын тікелей көрсетеді. Ешқандай «25%-дан» расталмаған бөлу жоқ. Егер форма есімдердің ресми жазылуын немесе әр аптаның жеке бөлінісін талап етсе, оларды тек команданың өзі ғана растай алады; репозиторий мұндай дәлдікті бермейді.
