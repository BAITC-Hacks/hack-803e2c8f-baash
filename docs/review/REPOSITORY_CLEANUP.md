## Аудит размера и ссылок

Самый большой отслеживаемый файл — скрытый региональный retrieval-корпус размером 5,7 МБ. Он намеренно обезличен и проверяется в `tests/security/test_research_artifact_gate.py`; его удаление ослабило бы privacy-gate проверки регрессий. Файл спецификации PDF размером 2,1 МБ и DOCX размером 0,97 МБ перенесены в архив. Каталог `ml/` занимает около 6,2 МБ, большую часть которого составляет скрытый корпус; `docs/` занимает около 3,3 МБ, включая исходное ТЗ. `uv.lock` и `pnpm-lock.yaml` остаются входными данными для воспроизводимости. PNG-диаграммы и снимки синтетического интерфейса — это доказательства для проверки, а не развёртываемые ассеты, которые можно удалять только по внешнему виду.

Проверены отслеживаемые сгенерированные файлы PDF/JSON/JSONL/PNG/joblib, `data/reports`, `ml/evaluation`, `release/evidence-index`, варианты Docker/Compose, workflows, скрипты, манифесты и импорты основных зависимостей. Старый PDF с вопросами заархивирован; текущий `output/pdf/govtech_business_questions.pdf` остаётся требуемым результатом. Базовый файл Compose и demo-override оба активны, найден один workflow CI. Избыточные варианты Docker/Compose или манифесты не удалялись. Ни один отслеживаемый файл в разработке, черновик или временный файл, а также закомментированный блок исходного кода не подлежали удалению; `infra/runbooks/BACKUP_RESTORE.md` — это активный runbook, а не резервная копия. Активный `demo.ps1` вызывает `scripts/demo_runtime.py`; три ранее существовавших неотслеживаемых вспомогательных скрипта демо остались нетронутыми.

В корне сохранены точки входа в проект, конфигурация, статус, ссылки на контракты/приёмку и handoff, требуемый `AGENTS.md`. Архивирование этого handoff в условиях, когда в `AGENTS.md` есть отдельные пользовательские изменения, оставило бы нарушенную инструкцию репозитория, поэтому он оставлен для последующего согласованного пересмотра.

## Изменения

- **Удалено:** отслеживаемые файлы не удалялись. Ни один файл не достиг порога безопасного удаления.
- **Архивировано:** десять файлов, перечисленных выше, с сохранением истории переименования Git и их содержимого.
- **Игнорирование / контекст сборки:** `.gitignore` теперь исключает стандартные локальные временные файлы; `.dockerignore` исключает данные исполняемого контура, секреты, документацию, тесты, исследовательские материалы и сгенерированные выходные данные, которые не копирует ни один Dockerfile. В контексте сохраняются исходный код, контракты и lock-файлы.
- **Навигация:** ссылки в `docs/README.md` и журнале проекта указывают на архив; датированные свидетельства аудита в журнале решений указывают на новый путь.

Никакие возможности исполняемого контура не изменились, поэтому `IMPLEMENTATION_STATUS.md` не переписывался. Эта очистка не доказывает, что каждый модуль или зависимость Python/TS не используются; будущее удаление должно продемонстрировать статическую и динамическую достижимость, а затем пройти соответствующие тесты.
