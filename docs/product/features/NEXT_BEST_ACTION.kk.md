# Next Best Action

## Бұл не

Бір War Room снимогына қолданылатын детерминдік ережелер. Әр ұсыныс іске қосылған кодтар мен тексеруші аша алатын артефактілерді атайды.

## Неге модель емес, ережелер

Кез келген ұсыныс бірнеше айдан кейін аудитор қоятын «неге мұны ұсындыңыз» деген сұраққа жауап беруі тиіс. Ереже іске қосылған кодтар мен оларды растайтын дәлелдерді көрсетеді. Осы деректер көлемінде және оператордың жақсы әрекеттері белгіленген корпуссыз оқытылған бағалау тексерілмейтін сан берер еді. Корпус пайда болғанда ережелер салыстырудың базалық алгоритмі болады.

## Рұқсат етілген ұсыныстар

| Әрекет | Шарт |
| --- | --- |
| `review_owner` | resolver үміткерді тапты |
| `resolve_ambiguity` | жауапкершілік бірмәнді емес |
| `avoid_handoff` | жазба цикл қаупін көрсетеді |
| `expand_incident` | үміткер қатысушылар күтілуде |
| `request_evidence` | расталған оқиғада тіркемелер жоқ |
| `escalate_unowned` | жауаптысыз белсенділік саясат шегінен асты |

Жиын жабық: оған кірмейтін ұсыныс жасалмайды.

## Сенімділік

Бұл ықтималдық емес, жазбадағы тәуелсіз растаулар санына негізделген аралық. Үш және одан көп — жоғары, екі — орташа, бір — төмен. Аралық жазбаның ұсынысты қаншалықты қолдайтынын көрсетеді.

## Шешімді алдын ала қарау

Тапсыру алдында preview үміткерлерді тіркелген фактілер бойынша салыстырады: сәйкес жауапкершілік ережелері, бұрынғы бас тартулар және бар ұқсас тексерілген нәтижелер. `basis` өрісі дәл `recorded_facts_only` мәніне тең: мұны болжам деу белгісіз білімді бар деп көрсету болар еді.

## Шекара

Модуль ұсыныс береді. Decision Gateway пен адам әрекетке рұқсат етеді. Әр ұсыныста `advisory_only: true` бар; модуль команда жібере алмайды.
