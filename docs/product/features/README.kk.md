# Pulse 109 өнім мүмкіндіктері

Pulse 109 бытыраңқы хабарламалардан ортақ қалалық мәселеге, қызметтердің келісілген жұмысына және тексерілетін нәтижеге өтуге көмектеседі. **ЖИ ұсынады — адам растайды.** Өтініш пен оқиға әртүрлі сәйкестігін сақтайды.

```text
Сигналдар → Radar → War Room → Ownership / Next Best Action
                             → Outbox / worker / adapter
                             → Closure / recurrence → Outcome Memory
Operations Center ағымдағы жағдайды көрсетеді
Data Lab сапа мен бастапқы жазбаларды ашады
Ask Pulse RU/KK сұрақтарына жауаптарды есептейді
Replay Lab шығарылым шешіміне дейін сақталған есептерді салыстырады
```

| Мүмкіндік             | Қазіргі жағдайы                                                                     | Техникалық сипаттамасы                                         |
| --------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Emerging Issues Radar | ✅ орын, уақыт және тақырып бойынша топтастыру; 🟡 семантика қолжетімсіз            | [EMERGING_ISSUES](EMERGING_ISSUES.kk.md), EN, техникалық жазба |
| Incident War Room     | ✅ жұмыс кеңістігі, синтетикалық карта және байланыстарды растау                    | [INCIDENT_WAR_ROOM](INCIDENT_WAR_ROOM.kk.md), EN              |
| Next Best Action      | ✅ ережелер жиынтығы; 🟡 базалық алгоритм ұсынымдары                                 | [NEXT_BEST_ACTION](NEXT_BEST_ACTION.kk.md), EN                 |
| Outcome Memory        | ✅ бақыланатын оқу; 🟡 расталған синтетикалық нәтижелер                             | [OUTCOME_MEMORY](OUTCOME_MEMORY.kk.md), EN                     |
| Operations Center     | ✅ есептегіштер, график және сілтемелері бар таспа                                  | [OPERATIONS_CENTER](OPERATIONS_CENTER.kk.md), EN               |
| Ask Pulse             | ✅ RU/KK, PostgreSQL есептеулері, шығу тегі, бастапқы жазбалар және экспорт         | [ASK_PULSE](ASK_PULSE.kk.md), EN, API және метрика егжей-тегжейі |
| Data Lab              | ✅ сапа, ағымдағы күйлер, тапсырулар, мерзімдер және бастапқы жазбалар              | [DATA_LAB](DATA_LAB.kk.md), EN, метрика анықтамалары           |
| Replay Lab            | 🟡 есептер тізімі және саясаттарды жиынтық салыстыру; жеке оқиға трассасы жазылмаған | [REPLAY_LAB](REPLAY_LAB.kk.md), EN, келісім-шарт шекарасы     |

Бұл қазақша бет — өнімге шолу; техникалық беттер егжей-тегжейлерді қамтиды, ал өзекті толық матрица — [FEATURE_STATUS](../../submission/FEATURE_STATUS.kk.md).

## Бірыңғай нәтиже семантикасы

`pulse109.capability` `available` (есептеу орындалды), `abstained` (есептеу қорытынды беруден бас тартты) және `unavailable` (есептеу орындалмады) күйлерін ажыратады. Ask Pulse сонымен қатар `clarification_required` күйін пайдаланады. Қолжетімсіздікті сәтті нөлдік нәтижеге айналдыруға болмайды. Себеп модельдің еркін мәтінімен емес, бақыланатын кодпен беріледі.

Golden World ішінде координаттар синтетикалық болып табылады және MapLibre/OSM арқылы көрсетіледі. Нақты экспорттық деректерде координаттар іс жүзінде жоқ; `COORDINATES_ABSENT` белгіленбеген география үшін айқын күй болып қала береді. Демо ойдан шығарылған мәтіндерді қамтыса да, Radar семантикалық сигналы қолжетімсіз (`CITIZEN_TEXT_ABSENT`).
