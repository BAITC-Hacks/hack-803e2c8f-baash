# Это не привычный вам Next.js

В этой версии есть несовместимые изменения: API, соглашения и структура файлов могут отличаться от данных, на которых вы обучались. Перед написанием любого кода прочитайте соответствующее руководство в `node_modules/next/dist/docs/` (путь определяется относительно каталога этого файла; в монорепозитории пакет `next` может быть недоступен из корня). Учитывайте уведомления об устаревании.

Этот блок записывает и повторно добавляет `next dev`; проверьте `node_modules/next/dist/server/lib/generate-agent-files.js`. Удаление блока из diff лишь заново создаёт незакоммиченное изменение; включение блока в коммит вместе с вашей работой сохраняет чистое рабочее дерево.
