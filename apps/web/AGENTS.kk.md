# Бұл сіз білетін Next.js емес

Бұл нұсқада бұрынғы нұсқалармен үйлеспейтін өзгерістер бар: API, келісімдер және файл құрылымы сіз оқытылған деректерден өзгеше болуы мүмкін. Кез келген кодты жазбас бұрын `node_modules/next/dist/docs/` ішіндегі тиісті нұсқаулықты оқыңыз (жол осы файлдың каталогына қатысты анықталады; монорепозиторийде `next` пакеті түбірден көрінбеуі мүмкін). Ескірген мүмкіндіктер туралы ескертулерді ескеріңіз.

Бұл блокты `next dev` жазады және қайта қосады; `node_modules/next/dist/server/lib/generate-agent-files.js` файлын тексеріңіз. Блокты diff-тен алып тастау тек коммиттелмеген өзгерісті қайта жасайды; оны жұмысыңызбен бірге коммитке қосу жұмыс ағашын таза сақтайды.
