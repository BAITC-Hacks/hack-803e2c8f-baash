# Манифесты датасетов

Файлы `synthetic_m3.jsonl` и `synthetic_m3_manifest.json` являются явно синтетическими тестовыми фикстурами. Они не содержат данных граждан и не должны использоваться для заявлений о качестве модели. Манифест фиксирует белый список признаков, исключения полей после принятия решения, неизменяемый хеш файла и политику группового временного разбиения.

Файлы `synthetic_m4_judged.jsonl`, `synthetic_m4_pairs.jsonl` и `synthetic_m4_manifest.json` проверяют исключительно механику поиска и проверки дубликатов. Манифест закрепляет как входные данные, так и детерминированный лексический/хеш-векторный резервный путь. Это не является репрезентативным подтверждением качества модели и не может использоваться для включения автоматического слияния.

Экспорты MLOps, полученные из этих фикстур, также являются строго синтетическими. Обратная связь операторов экспортируется в формате, совместимом с Label Studio, а файлы реестра и дрейфа представляют собой локальные манифесты совместимости; они не разрешают обучение, перевод моделей в промышленную эксплуатацию или принятие решений по дрейфу в production.

Файл `regional_retrieval_corpus_v1.jsonl` — это исторический региональный артефакт, весь текст которого скрыт до завершения проверки приватности B10. Он не может использоваться для обучения или оценки модели. Соседний манифест блокирует заявления о качестве и фиксирует дефекты исходного времени и обезличивания. Прежний текст остаётся в истории Git до отдельного решения владельца репозитория о сроке хранения.
