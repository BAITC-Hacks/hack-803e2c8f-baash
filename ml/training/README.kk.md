# Оқыту

Бекітілген бастапқы мәтіндер, белгілер және құқықтық негіз пайда болғанға дейін өндірістік қолдануға арналған оқыту әдейі енгізілмеген.

Синтетикалық базалық алгоритмді бағалаушы енді risk-coverage/AURC және жауап беруден бас тарту аралықтарын тіркейді. Жасалған артефактілер тек сынақ деректерін диагностикалауға арналған және модельдің өндірістік сапасын дәлелдемейді.
