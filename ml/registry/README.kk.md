# Модельдер тізілімінің сілтемелері

Бұл каталог өзгермейтін артефакт сілтемелері мен хештерді қамтиды, бірақ өзгеретін модель салмақтарын сақтамайды.

`ml/evaluation/synthetic_mlop/mlflow_registry_manifest.json` — champion, challenger және rollback синтетикалық бүркеншік атаулары бар, MLflow-пен үйлесімді жергілікті манифест. Ол модельді іске қоспайды және бекітілген MLflow енгізуін алмастырмайды.
